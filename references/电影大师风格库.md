# 电影大师风格库 Reference

> 本文件只提供视觉风格候选。规划或剧本需要建立、深化或校准视觉风格机制时，读取与当前项目相关的章节；用户未指定风格时用于建立不绑定具体人物/作品的默认视觉锚点，用户已指定时只用于深化和校准对应方向，不因进入阶段就整库读取。不能覆盖剧情因果、分镜职责、摄影设计、字幕策略或工具 schema。

## 本 Ref 关键要求

- 风格必须拆成光线、色彩、构图、材质和节奏等可观察机制，不能只写创作者名或“电影感”。
- 用户点名风格时保留沟通意图，但正式合同仍写项目语言的可执行视觉机制。
- 风格候选不得覆盖角色身份、剧情因果、分镜职责、字幕策略或工具 schema。
- 分镜和 Prompt 只采用与当前项目相关的机制，不机械复刻具体作品。

## 使用合同

- 风格锚点可以是用户指定的创作者/作品，也可以是不绑定具体人物的光线、色彩、构图、材质和节奏组合；不强制选择某位大师。
- 用户点名风格时保留其意图，但下游优先编译成项目语言的可观察视觉机制，不机械复刻具体作品。
- 本文件的镜头和元素均为候选，不规定每集出现次数；`storyboard.md` 是机位、运镜和镜头频率的唯一执行来源。
- 被采用的机制必须在分镜阶段写入 `storyboard.md` 规定的视觉叙事、核心意象、场面调度、声音和色彩合同；创作者姓名不能直接代替执行设计。
- Prompt 使用 `drama_plan.json.language_contract.video_language` 的自然导演语言；导演交付包为纯中文，英文 H3 成稿统一由 `h3-prompt-writing` 从可观察机制编译，本库不提供英文关键词表。
- 角色身份、产品、场景拓扑、用户原文、画幅和字幕规则优先于风格。

## 一、风格选择逻辑

### 为什么需要可执行的风格锚点

AI 短剧最大的风险之一是风格漂移。项目需要一份可执行的视觉合同，明确光线、色彩、构图、材质和镜头节奏；可以借助创作者或作品作为沟通锚点，但最终必须拆成这些可观察机制。

**禁止写法**：`电影风格`、`影视级质感`、`高级感`——太模糊，无法指导下游。
**正确写法**：`狭窄室内以门框分隔人物，钨丝暖光与窗外冷青对置，重复镜面反射表现关系错位`。用户主动点名创作者或作品时，可以在内部保留沟通锚点，但正式合同仍须拆成可观察机制。

### 风格路径判定

1. **是否有非真人强信号？**（用户指定动画形式 / 内容无法真人拍摄）
   - 是 → 选择动画流派（见第六章）
   - 否 → 继续
2. **用户是否点名了某位大师或作品？**
   - 是 → 保留用户原始意图，并拆解成视觉、镜头、色彩、声音和叙事机制
   - 否 → 优先用不绑定人物的机制组合；需要灵感时再查第三章
3. **一位大师有多个风格阶段时**，追加代表作限定（如 `王家卫《花样年华》风格的电影`）

## 三、重点大师深度解析（最常用的 5 位）

### 3.1 王家卫

**一句话定位**：用霓虹和时间拍都市人的孤独与错过。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 高饱和红绿蓝对撞、暗调大量阴影、霓虹灯光、雨夜、烟雾、胶片颗粒感、手持慢速快门拖影 |
| **镜头** | 手持轻晃到中晃、特写极多（眼睛/嘴唇/手）、镜面反射、慢镜头、抽帧（Step Printing）、低机位广角、失焦前景 |
| **色彩** | 红色（欲望/危险）、绿色（孤独/病态）、蓝色（忧郁/遥远）、黄色（温暖/怀旧）；高饱和高对比，暗部偏色 |
| **音乐** | 爵士乐、迷幻电子、粤语老歌、探戈；音乐是叙事核心，很多场景无对白全靠音乐；同一首音乐重复出现每次意义不同 |
| **叙事** | 非线性时间跳跃、多线交织、旁白（VO）是核心（诗意/哲理/伤感）、人物关系错位（永远错过）、没有明确结局 |
| **代表作品** | 《花样年华》《重庆森林》《春光乍泄》《阿飞正传》《堕落天使》 |
| **短剧应用候选** | 都市情感、关系错位或悬疑项目可按需提取色彩、雨夜、镜面、旁白或重复音乐机制；是否使用特写、手持、拖影和传播台词必须服从镜头职责、人物因果与生成稳定性，不以掩盖缺陷为目的 |

**风格限定建议**：怀旧/60年代→`王家卫《花样年华》风格`；现代都市/快节奏→`王家卫《重庆森林》风格`；同性/异国→`王家卫《春光乍泄》风格`。

### 3.2 韦斯·安德森

**一句话定位**：用绝对对称和马卡龙色拍成人的童话。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 绝对对称构图、高饱和马卡龙色板（粉/黄/蓝/橙/绿）、平面感强像插画、微缩模型感、章节化标题卡、正前方 push in |
| **镜头** | 固定镜头为主、正前方缓慢推镜、横向移动（Tracking Shot）、俯拍（God's Eye View）、快速摇镜（Whip Pan）、人物正对镜头说话（打破第四面墙） |
| **色彩** | 每个场景一个主色调，色彩统一；马卡龙色（柔和但鲜艳）；粉色/黄色/蓝色/橙色/绿色 |
| **音乐** | 60-70年代法国香颂/英国摇滚/民谣；原创配乐（木琴/钟琴/弦乐）有童话感；音乐节奏和画面动作精确同步 |
| **叙事** | 章节化叙事（每章有标题）、多线交织、黑色幽默（用严肃方式拍荒诞的事）、命运的偶然性、旁白用 deadpan（面无表情）语调 |
| **代表作品** | 《布达佩斯大饭店》《月升王国》《水中生活》《天才一族》《法兰西特派》 |
| **短剧应用** | ①喜剧/黑色幽默/冒险/广告剧情首选 ②对称构图与平面调度降低对复杂肢体调度的依赖（动作问题仍须拆镜或返回资产/视频责任层，不得用构图遮盖） ③马卡龙色板服务统一视觉 ④人物正对镜头说话须有叙事动机 ⑤章节化结构适合单元剧 ⑥deadpan旁白增加幽默感 |

### 3.3 大卫·芬奇

**一句话定位**：用冷灰和精密构图拍人性的黑暗。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 低调冷灰、精密对称构图、数字感质感（干净利落）、长焦压缩空间、阴影多明暗对比强、暗部偏绿亮部偏黄、雨夜是标志性场景 |
| **镜头** | 固定镜头+缓慢推轨、长焦镜头（压缩空间有压迫感）、特写多（眼睛/面部捕捉微表情）、缓慢推镜（Dolly In）、低角度/高角度交替、过肩镜头（OTS） |
| **色彩** | 冷灰色、蓝绿色、暗黄色；低饱和高对比；暗部偏绿亮部偏黄；红色是点缀（鲜血/关键物品） |
| **音乐** | 音乐克制甚至很多场景无音乐；电子乐/氛围音乐（冷峻/不安/科技感）；音乐是"底色"不是"主角"；静默是重要叙事工具；音效设计精确（滴答声/呼吸声/脚步声） |
| **叙事** | 线性叙事但信息释放克制（观众和主角一起探索真相）、反转是核心、人物疏离情感不外露、节奏缓慢但紧张（表面平静暗流涌动）、结尾通常是冷的 |
| **代表作品** | 《七宗罪》《搏击俱乐部》《消失的爱人》《社交网络》《龙纹身的女孩》《心灵猎人》 |
| **短剧应用** | ①悬疑/推理/犯罪/心理惊悚/高智商博弈首选 ②冷灰与阴影是悬疑/心理叙事语言，不得用于遮盖塑料感或结构错误（材质失真返回资产或视频责任层修复） ③精密构图+固定镜头稳定可执行 ④信息释放克制减少表演需求 ⑤静默比音乐更有张力 ⑥按镜头职责选择特写，眼神戏不作为固定公式 |

### 3.4 是枝裕和

**一句话定位**：用餐桌和日常拍家庭的温柔与遗憾。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 柔和自然光、暖色调低饱和（像褪色旧照片）、固定镜头/缓慢推拉、中景和全景为主、餐桌戏是标志、走廊和楼梯是重要叙事空间、门框构图 |
| **镜头** | 固定镜头为主几乎不用手持、缓慢横移和推拉（速度极慢）、中景和全景为主特写少而精、门框构图（暗示家庭边界和束缚）、多人同框时人物站位有层次 |
| **色彩** | 暖黄色、米白色、木色、浅绿色；低饱和；食物的颜色是画面中最鲜艳的部分 |
| **音乐** | 钢琴独奏为主（旋律简单但动人）；音乐只在3个节点出现（开场/关键情感转折/结尾）；中段几乎纯环境音 |
| **叙事** | 经典三幕式但节奏极慢、没有强烈戏剧冲突（情感在日常中累积）、留白多不把话说透、结尾通常是情感闭环不是大团圆、用"食物"和"餐桌"承载情感 |
| **代表作品** | 《小偷家族》《步履不停》《如父如子》《海街日记》《无人知晓》 |
| **短剧应用** | ①家庭/亲情/治愈/都市情感首选 ②中景+固定镜头减少对微表情的依赖 ③用场景和动作传递情感（餐桌戏/走廊戏） ④对白克制（很多情感用沉默和动作表达） ⑤暖色调+柔和自然光增加温暖感 ⑥AI数字人短剧：固定镜头和中景比手持和特写更适合AI |

### 3.5 斯坦利·库布里克

**一句话定位**：用一点透视和冷冽拍人类的荒谬与渺小。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 一点透视对称（镜头正对走廊/房间，消失点在画面中心）、缓慢推轨（沿轴线缓慢推进有压迫感和宿命感）、冷冽疏离、广角低机位（空间扭曲）、几何感强、大远景（人物在广阔空间中显得渺小）、俯拍（God's Eye View） |
| **镜头** | 一点透视推轨是标志（《闪灵》走廊/《2001》飞船走廊）、缓慢推轨（速度极慢累积压迫感）、广角低机位、大远景、固定镜头几乎不用手持、俯视 |
| **色彩** | 冷色调（蓝/白/灰）、高对比、红色是点缀（鲜血/关键物品）、每个场景一个主色调 |
| **音乐** | 古典音乐（贝多芬/巴赫/施特劳斯）、现代古典（利盖蒂的合唱）、音乐和画面情绪错位（暴力场景用优雅古典乐）、很多场景无音乐只有环境音 |
| **叙事** | 线性叙事时间跨度大、人类的荒谬和渺小是核心主题、人物疏离像被观察的实验对象、节奏缓慢但有累积压迫感、结尾通常开放甚至神秘 |
| **代表作品** | 《2001太空漫游》《闪灵》《发条橙》《全金属外壳》《巴里·林登》 |
| **短剧应用候选** | 科幻、悬疑、心理惊悚或高概念项目可按需采用一点透视、几何构图、冷色关系和音乐错位；具体机位、节奏和色彩必须服务人物与信息，不得用风格遮盖结构、表演或连续性错误 |

## 五、风格混搭指南

需要混搭时，一位作为主锚点，另一位只承担明确的辅助职责；不固定比例，也不混合相互冲突的镜头与色彩规则。

### 混搭三原则

1. **同流派混搭最安全**：同一流派的大师风格相近，混搭不容易出问题（如王家卫+杜可风、是枝裕和+河濑直美）
2. **跨流派混搭要有明确的"混搭点"**：明确你想要什么（如"韦斯·安德森的视觉 + 大卫·芬奇的叙事"），视觉和叙事分开混搭
3. **不要混搭超过两位**：三位以上会变成风格混乱

### 经典混搭组合表

| 主锚点职责 | 辅锚点职责 | 混搭效果 | 适用题材 |
|---|---|---|---|
| 王家卫 | 杜可风 | 更强烈的港风迷离感 | 都市情感、悬疑、黑帮 |
| 是枝裕和 | 河濑直美 | 更有自然气息的家庭治愈 | 家庭、治愈、自然 |
| 韦斯·安德森 | 昆汀 | 童话感的暴力美学 | 黑色幽默、犯罪、冒险 |
| 大卫·芬奇 | 库布里克 | 更有压迫感的悬疑 | 悬疑、心理惊悚、科幻 |
| 诺兰 | 泰伦斯·马利克 | 有诗意的科幻史诗 | 科幻、高概念、宏大叙事 |
| 王家卫 | 是枝裕和 | 有家庭温度的都市情感 | 都市情感、家庭、治愈 |

## 七、AI 短剧风格实现候选

### 7.1 扬长避短的风格选择

| AI 的局限 | 适合的风格/技巧 | 不适合的风格/技巧 |
|---|---|---|
| 微表情有限 | 用动作、距离、道具和听者反应外化情绪；景别与光线按信息职责选择 | 只依赖细微表情传递关键剧情 |
| 动作僵硬 | 缩短动作链、拆分起势/接触/反馈/结果，并选择稳定可执行的调度 | 未拆解的复杂打斗、舞蹈、跑酷或无节点长镜头 |
| 多人同框困难 | 正反打、单人镜头拼接、核心场景2-3人、群像用蒙太奇 | 5人以上同框、复杂群像调度 |
| 口型同步有误差 | 台词不要太密集、关键金句单独成句、少用生僻字、用旁白代替部分对白 | 机关枪式快嘴、大段绕口令、快速对话 |
| 场景/道具一致性差 | 核心道具精确描述、按剧情合并同功能场景、服装发型在小传中锁定；单场故事可只用 1 个场景 | 无独立剧情功能的大量场景切换、无触发的复杂服装变化 |
| 不擅长留白 | 用画面元素填充留白（风吹窗帘、钟表滴答、特写道具） | 纯静止的长镜头、无内容的空镜 |
| 渲染有"塑料感" | 从材质、光源依据、色彩关系和景深层次定向修复 | 用暗调、滤镜、颗粒或裁切掩盖结构错误 |

### 7.2 常用 AI 短剧风格示例

按对 AI 短剧的适配度排序；具体机制见第三章深度解析与第八章元素清单。

| 风格 | 为什么适合 AI 短剧 |
|---|---|
| **王家卫** | 色彩对照、雨夜、镜面、重复音乐和主观旁白可外化关系错位与记忆，不依赖细密表演 |
| **韦斯·安德森** | 对称、平面调度、有限色板和克制表演适合规则明确的荒诞或家庭关系，固定机位稳定可执行 |
| **大卫·芬奇** | 精密构图、可读证据、静默与精确音效支撑程序、调查和控制主题，信息释放克制减少表演需求 |
| **是枝裕和** | 中景与固定机位减少对微表情的依赖，餐桌、日常动作和环境音承载情感，对白克制 |
| **库布里克** | 一点透视、固定机位、大远景和音乐错位替代复杂调度，减少对人物表演的依赖 |

共同护栏：风格只可降低对模型弱项的依赖，**不得用于遮盖结构、表演或连续性错误**（包括不得用芬奇式暗部藏错）；慢动作仅在时间感本身承担剧情职责时使用；人物正对镜头说话必须有叙事动机。

### 7.3 AI 短剧电影感的 10 个具体技巧

1. **用光影补充表演**——光影必须服务人物选择和场景因果，不把冷暖色机械等同于善恶。
2. **按信息选择特写**——眼睛、嘴部、手部、道具或全脸根据镜头职责选择，不固定只拍某个部位。
3. **旁白按需使用**——复杂内心优先通过行动和关系外化；只有旁白承担不可替代职责时才使用。
4. **按职责选择运动**——固定、推轨、手持、环绕、升降或快切由 `storyboard.md` 决定，禁止全片统一缓慢运镜。
5. **慢动作和定格不是默认补救**——只在时间感变化本身具有剧情意义且模型能力允许时采用。
6. **用道具和场景叙事**——AI数字人不擅长"演"，但道具和场景可以"说"。一封信、一块怀表、一个空座位、一扇半开的门，用道具和场景传递信息和情感，减少对人物表演的依赖。
7. **色彩统一和风格化**——色彩合同只负责统一叙事视觉。出现材质失真或"塑料感"时必须返回资产或视频责任层修复，不得用调色掩盖生成缺陷。
8. **音效和静默**——AI短剧的声音设计比画面更能提升质感。关键场景优先用近似静默或主观静默：移除 BGM 和多数环境层，保留能定位身体或空间的精确音效（滴答声、呼吸声、脚步声）；完全静默只在世界逻辑或主观听觉成立时使用。
9. **正反打代替多人同框**——AI数字人多人同框容易出现比例失调和一致性问题。用正反打（A说话拍A，B说话拍B）代替多人同框，既解决了技术问题，又符合电影对话戏的标准拍法。
10. **风格锚点全程贯彻**——选择风格锚点后，从剧本意图、角色/道具资产、视频 Prompt、实际成片画面核对到调色方向，全程贯彻同一组可观察机制。风格统一是电影感的基础。

### 7.4 AI 短剧风格实现检查清单

| ✓ | 检查项 | 达标标准 |
|---|---|---|
| □ | 风格锚点 | 剧本头明确可执行的光线、色彩、构图、材质和节奏；可选创作者/作品锚点 |
| □ | 色彩统一 | 全剧色彩风格统一，有明确主色调，不是每集颜色都不一样 |
| □ | 光影设计 | 关键场景有光影设计（半明半暗/逆光/轮廓光），不是平光/大白光 |
| □ | 镜头语言 | 有统一的镜头语言风格（固定/手持/推轨/对称），不是随便拍 |
| □ | 旁白使用 | 适当使用旁白传递人物内心，减少对AI表演的依赖 |
| □ | 特写策略 | 情感时刻用眼睛/嘴唇特写，不是全脸特写 |
| □ | 道具叙事 | 用核心道具和场景传递信息，不是全靠对白解释 |
| □ | 声音设计 | 有关键场景的静默和精确音效，不是全程BGM填满 |
| □ | 多人同框 | 主行动者、关系轴线和每个角色反应清楚；复杂度超限时拆镜 |
| □ | 速度设计 | 正常速度、慢动作、停顿或快切均有叙事理由，不用慢动作填时长 |
| □ | 一致性 | 核心场景、核心道具、角色外观在全剧中保持一致 |
| □ | 下游贯彻 | 资产、分镜、视频 Prompt、实际成片画面核对和调色环节都贯彻了同一种风格，不是只有剧本写了风格 |

以下清单是风格识别与选型素材，机制解释以第三章各位大师深度解析为唯一权威；每个场次只选择能服务当前叙事职责的少量元素，不要求固定数量或频率。同一元素可被多位大师使用（固定机位、雨夜、俯拍、门框构图等），归属看整体机制组合，不按单个元素贴标签。

|---|---|
| 王家卫 | 慢门拖影/抽帧卡顿（人物走动时背景拖出光影轨迹、动作轻微跳帧）；霓虹红绿蓝对撞与雨夜湿街反光；烟雾、镜面反射与门框/窗框构图（人被框住或出现在镜、玻璃、水面中）；眼睛嘴唇特写；诗意 VO 与重复音乐 |
| 韦斯·安德森 | 绝对对称、人物居中；正面缓推、横向移镜、快摇转场；马卡龙有限色板、每场一色；章节标题卡与微缩模型平面感；俯拍；打破第四面墙与 deadpan 旁白 |
| 大卫·芬奇 | 冷灰低饱和、暗部偏绿亮部偏黄；精密对称与固定机位缓慢推轨；长焦压缩空间；眼睛特写与 OTS 过肩；近似静默加精确音效（滴答/呼吸/脚步，完全静默须有叙事依据）；信息释放克制 |
| 是枝裕和 | 餐桌戏、食物是画面中最鲜艳的颜色；固定机位与中景全景为主；柔和自然光、暖黄木棕低饱和；走廊、楼梯与门框作为叙事空间；中段环境音、对白克制 |
| 库布里克 | 一点透视中轴推轨；广角低机位、大远景人物渺小；冷蓝白高对比与几何构图，红色只作关键物品点缀；俯拍如观察实验对象；古典乐与暴力/紧张画面错位；静默与环境音 |

### 风格一致性检查

每集完成分镜后，对照清单检查：
- □ 选中的风格元素是否服务镜头职责，而不是为了凑数量？
- □ 色彩基调和该大师一致吗？
- □ 镜头语言（固定/手持/推轨/对称）和该大师一致吗？
- □ 有没有混入其他大师的标志性元素？（比如王家卫风格里出现了韦斯·安德森的对称构图）
