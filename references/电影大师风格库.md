# 电影大师风格库 Reference

> 本文件只提供视觉风格候选。规划或剧本需要建立、深化或校准视觉风格机制时，读取与当前项目相关的章节；用户未指定风格时用于建立不绑定具体人物/作品的默认视觉锚点，用户已指定时只用于深化和校准对应方向，不因进入阶段就整库读取。不能覆盖剧情因果、分镜职责、摄影设计、字幕策略或工具 schema。

## 本 Ref 关键要求

- 风格必须拆成光线、色彩、构图、材质和节奏等可观察机制，不能只写创作者名或“电影感”。
- 用户点名风格时保留沟通意图，但正式合同仍写项目语言的可执行视觉机制。
- 风格候选不得覆盖角色身份、剧情因果、分镜职责、字幕策略或工具 schema。
- 分镜和 Prompt 只采用与当前项目相关的机制，不机械复刻具体作品。

## 使用合同

- 风格锚点可以是用户指定的创作者/作品，也可以是不绑定具体人物的光线、色彩、构图、材质和节奏组合；不强制选择某位大师。
- 用户点名风格时保留其意图，但下游优先编译成项目语言的可观察视觉机制，不机械复刻具体作品。
- 本文件的镜头和元素均为候选，不规定每集出现次数；`storyboard.md` 是机位、运镜和镜头频率的唯一执行来源。
- 被采用的机制必须在分镜阶段写入 `storyboard.md` 规定的视觉叙事、核心意象、场面调度、声音和色彩合同；创作者姓名不能直接代替执行设计。
- 直接向 `h3-prompt-writing` 提供已确认导演源，确有需要时再附可选交付包；成稿语言取 `drama_plan.json.language_contract.video_language`，从可观察机制编译，本库不提供关键词表。
- 角色身份、产品、场景拓扑、用户原文、画幅和字幕规则优先于风格。

## 一、风格选择逻辑

### 为什么需要可执行的风格锚点

AI 短剧最大的风险之一是风格漂移。项目需要一份可执行的视觉合同，明确光线、色彩、构图、材质和镜头节奏；可以借助创作者或作品作为沟通锚点，但最终必须拆成这些可观察机制。

**禁止写法**：`电影风格`、`影视级质感`、`高级感`——太模糊，无法指导下游。
**正确写法**：`狭窄室内以门框分隔人物，钨丝暖光与窗外冷青对置，重复镜面反射表现关系错位`。用户主动点名创作者或作品时，可以在内部保留沟通锚点，但正式合同仍须拆成可观察机制。

### 风格路径判定

1. **用户是否已明确呈现形态？**
   - 已明确 → 保留该形态；动画可查第六章，真人质感的幻想内容不自动改成动画
   - 未明确 → 正式生产按 `planning.md` 选择形态；纯文字任务只在确实影响创作时澄清，不从技术难度擅定形态
2. **用户是否点名了某位大师或作品？**
   - 是 → 保留用户原始意图，并拆解成视觉、镜头、色彩、声音和叙事机制
   - 否 → 优先用不绑定人物的机制组合；需要灵感时再查第三章
3. **一位大师有多个风格阶段时**，追加代表作限定（如 `王家卫《花样年华》风格的电影`）

## 二、真人电影六大流派速查

此处是检索用的视觉倾向分组，并非电影史上的六种正式流派；导演与摄影师角色不同，同一创作者也有跨作品、跨时期的差异。下表只帮助定位相关作品，不从人名推导固定摄影配方。

| 流派 | 核心气质 | 代表大师 | 适用题材/情绪 |
|---|---|---|---|
| **东方生活流/家庭治愈** | 温柔、克制、日常、诗意 | 是枝裕和、李安、侯孝贤、岩井俊二 | 家庭、治愈、青春、亲情、微电影 |
| **港风霓虹/怀旧胶片** | 城市灯色、记忆与主观时间 | 王家卫、杜可风（摄影） | 都市情感、怀旧、悬疑、黑帮 |
| **极简对称/高饱和作者美学** | 几何组织、有限色板、形式化表演 | 韦斯·安德森的相关作品 | 喜剧、黑色幽默、冒险、广告剧情 |
| **极简冷冽/精密构图** | 冷静、精密、疏离、悬疑 | 大卫·芬奇、库布里克、迪金斯、诺兰 | 悬疑、科幻、心理惊悚、高智商、犯罪 |
| **诗性自然/影展作者** | 诗意、自然、冥想、神秘 | 泰伦斯·马利克、阿彼察邦、河濑直美 | 文艺、诗意、自然、影展、治愈 |
| **社会现实主义/纪实感** | 真实、粗糙、有力、共情 | 达内兄弟、肯·洛奇、贾樟柯 | 社会现实、打工人、底层、公益、纪实 |

## 三、重点大师深度解析（最常用的 5 位）

以下是从所列代表作中观察到的候选机制，不表示创作者所有作品均如此，也不构成模型适配结论；引用时限定作品与当前场面作用，音乐、素材等仍需独立授权。

### 3.1 王家卫

**一句话定位**：用霓虹和时间拍都市人的孤独与错过。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 高饱和红绿蓝对撞、暗调大量阴影、霓虹灯光、雨夜、烟雾、胶片颗粒感、手持慢速快门拖影 |
| **镜头** | 手持轻晃到中晃、特写极多（眼睛/嘴唇/手）、镜面反射、慢镜头、抽帧（Step Printing）、低机位广角、失焦前景 |
| **色彩** | 可观察红绿对置、实景灯色与肤色的冲突、冷暖分区和暗部偏色；具体情绪意义来自作品语境，红绿蓝不各自固定对应一种心理 |
| **音乐** | 爵士乐、迷幻电子、粤语老歌、探戈；音乐是叙事核心，很多场景无对白全靠音乐；同一首音乐重复出现每次意义不同 |
| **叙事** | 部分作品通过时间省略、多视角、主观旁白与重复情境重释关系；结局可保留余味，不等于所有作品都无明确结果 |
| **代表作品** | 《花样年华》《重庆森林》《春光乍泄》《阿飞正传》《堕落天使》 |
| **短剧应用候选** | 都市情感、关系错位或悬疑项目可按需提取色彩、雨夜、镜面、旁白或重复音乐机制；是否使用特写、手持、拖影和传播台词必须服从镜头职责、人物因果与生成稳定性，不以掩盖缺陷为目的 |

**风格限定建议**：怀旧/60年代→`王家卫《花样年华》风格`；现代都市/快节奏→`王家卫《重庆森林》风格`；同性/异国→`王家卫《春光乍泄》风格`。

### 3.2 韦斯·安德森

**一句话定位**：用绝对对称和马卡龙色拍成人的童话。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 绝对对称构图、高饱和马卡龙色板（粉/黄/蓝/橙/绿）、平面感强像插画、微缩模型感、章节化标题卡、正前方 push in |
| **镜头** | 正面构图、横向移镜、俯拍和快摇等形式化组织；人物正面朝向摄影机不自动等于打破第四面墙，须区分场内对视与向观众讲话 |
| **色彩** | 每个场景一个主色调，色彩统一；马卡龙色（柔和但鲜艳）；粉色/黄色/蓝色/橙色/绿色 |
| **音乐** | 60-70年代法国香颂/英国摇滚/民谣；原创配乐（木琴/钟琴/弦乐）有童话感；音乐节奏和画面动作精确同步 |
| **叙事** | 章节化叙事（每章有标题）、多线交织、黑色幽默（用严肃方式拍荒诞的事）、命运的偶然性、旁白用 deadpan（面无表情）语调 |
| **代表作品** | 《布达佩斯大饭店》《月升王国》《水中生活》《天才一族》《法兰西特派》 |
| **短剧应用** | 形式化构图、有限色板与克制表演可参与荒诞或关系表达；是否使用章节、正面构图和 deadpan 由当前故事决定，不以简化表演为默认目的 |

### 3.3 大卫·芬奇

**一句话定位**：用冷灰和精密构图拍人性的黑暗。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 低调冷灰、精密对称构图、数字感质感（干净利落）、长焦压缩空间、阴影多明暗对比强、暗部偏绿亮部偏黄、雨夜是标志性场景 |
| **镜头** | 固定镜头+缓慢推轨、长焦镜头（压缩空间有压迫感）、特写多（眼睛/面部捕捉微表情）、缓慢推镜（Dolly In）、低角度/高角度交替、过肩镜头（OTS） |
| **色彩** | 冷灰色、蓝绿色、暗黄色；低饱和高对比；暗部偏绿亮部偏黄；红色是点缀（鲜血/关键物品） |
| **音乐** | 音乐克制甚至很多场景无音乐；电子乐/氛围音乐（冷峻/不安/科技感）；音乐是"底色"不是"主角"；静默是重要叙事工具；音效设计精确（滴答声/呼吸声/脚步声） |
| **叙事** | 视点控制、信息差与程序细节可形成压力；《社交网络》《消失的爱人》等还利用非线性和视角变化，不统一归为线性、慢节奏或以反转为核心 |
| **代表作品** | 《七宗罪》《搏击俱乐部》《消失的爱人》《社交网络》《龙纹身的女孩》《心灵猎人》 |
| **短剧应用** | 可借证据的可读性、精确空间和受控信息组织调查或权力主题；静默、运动和特写按场面选择，没有哪种声音或机位天然更有张力、更适合 AI |

### 3.4 是枝裕和

**一句话定位**：用餐桌和日常拍家庭的温柔与遗憾。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 柔和自然光、暖色调低饱和（像褪色旧照片）、固定镜头/缓慢推拉、中景和全景为主、餐桌戏是标志、走廊和楼梯是重要叙事空间、门框构图 |
| **镜头** | 可观察家庭空间中的同框、视线与门框分隔；具体摄影随作品变化，《无人知晓》等包含手持观察，不能概括为几乎不用手持 |
| **色彩** | 暖黄色、米白色、木色、浅绿色；低饱和；食物的颜色是画面中最鲜艳的部分 |
| **音乐** | 配乐与环境音关系因作品而异，可观察音乐何时进入人物生活；不存在开场、转折、结尾三节点的通用配乐配额 |
| **叙事** | 日常劳动、相处和伦理处境累积人物关系；《小偷家族》《无人知晓》等也有强烈现实冲突，不统一称为慢三幕或无强冲突 |
| **代表作品** | 《小偷家族》《步履不停》《如父如子》《海街日记》《无人知晓》 |
| **短剧应用** | 从人物共同生活的事务、同框关系和声音中寻找表达，不先补餐桌、门框、暖色或沉默；表演与摄影保留故事所需，模型风险按实际失败处理 |

### 3.5 斯坦利·库布里克

**一句话定位**：用一点透视和冷冽拍人类的荒谬与渺小。

| 维度 | 具体特征 |
|---|---|
| **视觉** | 一点透视对称（镜头正对走廊/房间，消失点在画面中心）、缓慢推轨（沿轴线缓慢推进有压迫感和宿命感）、冷冽疏离、广角低机位（空间扭曲）、几何感强、大远景（人物在广阔空间中显得渺小）、俯拍（God's Eye View） |
| **镜头** | 《闪灵》的走廊跟随、《2001》的几何空间等提供不同观看关系；也有手持与快速动作，不将一点透视、缓推或固定机位视为所有场面的统一手法 |
| **色彩** | 冷色调（蓝/白/灰）、高对比、红色是点缀（鲜血/关键物品）、每个场景一个主色调 |
| **音乐** | 古典音乐（贝多芬/巴赫/施特劳斯）、现代古典（利盖蒂的合唱）、音乐和画面情绪错位（暴力场景用优雅古典乐）、很多场景无音乐只有环境音 |
| **叙事** | 线性叙事时间跨度大、人类的荒谬和渺小是核心主题、人物疏离像被观察的实验对象、节奏缓慢但有累积压迫感、结尾通常开放甚至神秘 |
| **代表作品** | 《2001太空漫游》《闪灵》《发条橙》《全金属外壳》《巴里·林登》 |
| **短剧应用候选** | 科幻、悬疑、心理惊悚或高概念项目可按需采用一点透视、几何构图、冷色关系和音乐错位；具体机位、节奏和色彩必须服务人物与信息，不得用风格遮盖结构、表演或连续性错误 |

## 五、风格混搭指南

需要混搭时按机制写明各自职责与相互关系；不按创作者人数或比例验收，也不让互相抵消的视点、色彩或时间规则同时支配同一场面。

### 混搭三原则

1. **先比机制**：同一标签下的作品也可能不兼容；摄影、表演、声音与叙述须放回具体作品理解。
2. **说明组合点**：例如有限色板用于空间辨识，信息差用于人物博弈，不能只叠两个名字。
3. **检查实际冲突**：只处理令观看关系失读或抵消表达的冲突，不凭来源人数判定混乱。

## 七、AI 短剧风格实现候选

### 7.1 扬长避短的风格选择

先按场内人物关系与观看意图设计，再处理当前模型实际暴露的失败。下列方法只用于对应问题，不提前把所有场面改成单人镜头、固定镜头或慢镜头。

| AI 的局限 | 适合的风格/技巧 | 不适合的风格/技巧 |
|---|---|---|
| 微表情有限 | 先检查人物策略、距离、姿态与停留是否可读；具体表演失败时再定向调整 | 把每次情绪都补成反应镜或某个面部部位的特写 |
| 动作僵硬 | 先保留已确认调度与可理解的动作省略；发生具体路径、接触或相位错误时，只澄清该处关系 | 预先把每次动作拆成起势、接触、反馈、结果，或仅因动作复杂就强拆镜头 |
| 多人同框困难 | 依据人物距离、视线、遮挡和注意力组织同框；出现身份、比例或站位错误时修对应输入与调度 | 按固定人数禁令删人，或默认用正反打替代场内关系 |
| 口型同步有误差 | 保留已确认台词、发声类型与音色，核对发声归属、时间与实际口型失败，再修对应段 | 为迁就模型擅改台词、用旁白替换对白或切走原定画面 |
| 场景/道具一致性差 | 先核对 approved 输入、版本、状态与实际采用范围，定向修复不一致处 | 编译时自主合并场景、修改剧情或用裁切隐藏状态冲突 |
| 不擅长留白 | 保留原定画面范围、时长、环境声与未回应的关系；只有生成结果偏离设计时才修对应变量 | 用窗帘、钟表、道具特写或无依据的动作填满留白 |
| 渲染有"塑料感" | 从材质、光源依据、色彩关系和景深层次定向修复 | 用暗调、滤镜、颗粒或裁切掩盖结构错误 |

### 7.2 常用 AI 短剧风格示例

以下无适配度排序，也没有跨模型实测结论。按当前叙事问题寻找机制，具体观察见第三章；生成能力以当前模型和实际结果核实。

| 风格来源 | 可研究的表达问题 |
|---|---|
| **王家卫** | 记忆、时间省略、关系错位与主观声音如何相互作用 |
| **韦斯·安德森** | 形式化空间、表演与叙述层次如何组织荒诞和情感 |
| **大卫·芬奇** | 受控视点、证据与空间如何组织程序和权力 |
| **是枝裕和** | 日常事务、共同生活与未说出口的关系如何被观察 |
| **库布里克** | 人物、几何空间、运动与声音错位如何改变观看距离 |

共同原则：风格服务本片的表达，不以回避表演或遮盖错误为目的。慢动作、正面讲话与静默均须来自当前观看设计，不作默认配方。

### 7.3 AI 短剧电影感的 10 个具体技巧

1. **用光影补充表演**——光影必须服务人物选择和场景因果，不把冷暖色机械等同于善恶。
2. **按信息选择特写**——眼睛、嘴部、手部、道具或全脸根据镜头职责选择，不固定只拍某个部位。
3. **旁白按需使用**——复杂内心优先通过行动和关系外化；只有旁白承担不可替代职责时才使用。
4. **按观看意图选择摄影**——固定、缓慢运动、快速运动及摄影起停由场内关系和 `storyboard.md` 决定；可以连续使用同一种方式，也可以在具体时刻改变，不按类别配额或情绪强度自动分配。
5. **慢动作和定格不是默认补救**——只在时间感变化本身具有剧情意义且模型能力允许时采用。
6. **保留道具和场景的具体职责**——道具、空间与人物表演共同构成场内关系，只表达已确认的用途；不默认插入道具镜、空座位或门缝特写替代表演。
7. **色彩统一和风格化**——色彩合同只负责统一叙事视觉。出现材质失真或"塑料感"时必须返回资产或视频责任层修复，不得用调色掩盖生成缺陷。
8. **保留已确认的听觉关系**——声音距离、环境、音乐与静默按场内空间和观看意图组织；保留发声归属与听觉变化，不要求关键场景静默，也不默认加入滴答、呼吸或脚步来制造质感。
9. **保留对话中的观看选择**——同框、画外说话、停在听者或暂不展示反应，取决于观众此刻与谁处在一起。正反打只是可选方法，不按谁说话就切给谁；出现具体同框失败时先修人物空间与素材，再决定是否需要调整已确认设计。
10. **风格锚点全程贯彻**——选择风格锚点后，从剧本意图、角色/道具资产、视频 Prompt、实际成片画面核对到调色方向，全程贯彻同一组可观察机制。风格统一是电影感的基础。

### 7.4 AI 短剧风格实现检查清单

本表只在风格诊断时选相关项并入已有审校，不另生成一份逐项报告。

| ✓ | 检查项 | 达标标准 |
|---|---|---|
| □ | 风格锚点 | 剧本头明确可执行的光线、色彩、构图、材质和节奏；可选创作者/作品锚点 |
| □ | 色彩统一 | 色彩关系符合已确认意图，可随地点、时代或人物经验有意变化 |
| □ | 光影设计 | 光源、可见范围和人物关系符合场景意图；平光、逆光或暗部均可，不以固定光型判定完成 |
| □ | 镜头语言 | 视点、画面范围、摄影起停与停留延续整场观看设计，变化与不变化都有具体依据 |
| □ | 旁白使用 | 旁白承担已确认的叙事职责，未被用来替换原定对白或掩盖表演失败 |
| □ | 特写策略 | 需要看近的具体内容由关系与观看距离决定；情感可以留在全脸、身体、同框或画外，不固定拍眼睛与嘴唇 |
| □ | 道具叙事 | 实际使用的道具与空间有真实职责，不强加象征物或证据特写 |
| □ | 声音设计 | 声音距离、环境、音乐与静默符合已确认听觉关系，未被统一配乐或必须静默的公式改写 |
| □ | 多人同框 | 人物身份、空间关系与当前注意力可读；不要求展示每个角色反应，具体失败才定向修复 |
| □ | 速度设计 | 正常速度、慢动作、停顿或快切均有叙事理由，不用慢动作填时长 |
| □ | 一致性 | 身份与空间可追踪，剧情引起的状态变化有依据 |
| □ | 下游贯彻 | 资产、分镜、视频 Prompt、实际成片画面核对和调色环节都贯彻了同一种风格，不是只有剧本写了风格 |

### 风格一致性检查

每集完成分镜后，回看整场的人物关系、观看距离、时间感和声音如何共同起作用。核对的是项目已确认的创作意图能否成立，而不是色彩、机位或特写是否像某位大师；不同来源的机制可以共存，只处理实际互相抵消或令场内关系失读的冲突，不因出现另一位创作者也使用过的元素而返工。
