# 全流程排障 Ref

当任一阶段出现错误、结果不符合预期、状态与文件不一致，或不知道应返回哪个阶段时读取本文件。本文件是重试预算、责任阶段和恢复路径的唯一权威。

## 本 Ref 关键要求

- 先读当前实际文件和状态，不凭聊天记忆判断。
- 返回最早出错层级；上游合同正确但模型执行漂移时留在当前生成阶段处理。
- 同一工具执行缺陷最多自动定向重试 1 次；视频生成、重生或编辑不适用自动重试。已返回的结果可作为候选展示，仍须实际观看并在对话中说明关键内容问题；返修/重生需要真实授权。第二轮仍失败则停止并升级给用户或返回责任阶段。
- 修复只补失败项和必要上游，不覆盖最后一个已确认版本。

## 排障原则

1. 先按字段路径定点读 `drama_plan.json`（读取面合同见 planning.md，不整读）、`制作状态.json`、`操作日志.jsonl` 和当前实际文件，不凭聊天记忆判断。
2. 区分“工具调用失败”“文件结构错误”“内容错误”“实际媒体质量错误”，不能只看接口是否成功。
3. 返回最早出错层级：规划错回规划，剧情错回剧本，镜头合同错回分镜，已批准 CHR/PROP 设定或确认采用的 VOICE 修复资产本身错误回资产，生成片段中的身份、场景、道具、原生声线、口型或运动执行漂移回视频，拼接/混音/字幕错回成片。
4. 保留最后一个已确认版本，只创建新版本，不覆盖。
5. 外部调用按部分成功处理：先盘点真实产物，只补失败项。
6. 同一缺陷最多自动定向重试 `1` 次：初始失败为第 1 轮，修改明确变量后的自动重试为第 2 轮；第 2 轮仍存在同一缺陷时停止，不再自动生成，按最早责任层级升级。视频生成、重生或编辑的结果检查不触发自动重试；视频工具返回可播放/可渲染结果后仍须实际观看并记录内容观察，关键问题如实向用户说明但不阻断候选展示，是否返修由用户主动决定。未提交的文稿、分镜或Prompt缺陷先在原授权范围内修复；已生成视频的返修/重生需用户授权及新一轮参数确认。只有用户明确提出修改、返修、重生、新视频或继续视频任务，并重新完成视频参数确认后，才可提交新的 多媒体视频（`h3` Ref2VA）、图生视频（`h3` I2VA） 或 视频重生成（`h3`） 调用。
7. 每次修复记录问题证据、归属层级、修复动作、版本和复验结果。

## 缺陷编号

| 前缀 | 类别 | 典型问题 |
|---|---|---|
| `V` | 视觉 | 身份漂移、复制主体、道具/场景/光线漂移、随机文字或水印 |
| `A` | 音频 | 静音或漏说、错人、声线漂移、口型错位、截断、噪声或响度突变 |
| `F` | 衔接 | 构图位置跳变、动作回弹/重复、光色跳变、声音桥断裂、未经检查的文件边界直拼 |
| `S` | 镜头执行 | 镜头遗漏、单动作拖时、运镜同质化、动作复杂度超限、计划与实际不符 |
| `N` | 叙事 | 动机或因果断裂、钩子未兑现、高潮依赖巧合、台词缺少证据 |
| `C` | 确认 | 未经视频生成确认就准备生成、确认范围与实际生成不符、确认过期后沿用旧授权、确认后修改参数未重新确认 |

每个缺陷记录首次时间码、证据、责任阶段、修改变量、修复版本和复验结果。上游合同正确但模型执行仍漂移时留在当前生成阶段，改用拆分片段、更换已确认兼容模型或如实声明能力限制，不得无依据使上游失效。

## 快速定位

| 症状 | 首查阶段 | 证据 | 首选修复 |
|---|---|---|---|
| 受众、平台、风格或规模反复变化 | 规划 | `drama_plan.json` revision、开放问题和确认状态 | 返回规划，重新确认并使下游失效 |
| 剧情平、人物被动、反转无铺垫 | 剧本 | 场次因果、信息差账本、台词证据链 | 重写最早失效场次 |
| 片段只有一个慢动作、摄影重复或全是推拉 | 分镜 | 十五列详细分镜、总控卡逐段执行区、shot_plan、实际画面发展、观看对象与切点 | 先判断该段希望观众如何观看，再重构摄影过程、观察对象、焦点、停顿或切点；不按运镜类别清单机械替换。仅在真实观看意图需要时增加摄影变化 |
| 结构化台词存在但视频无声 | 视频 | 检查提交给模型的 H3 成稿、以及作为其来源的 `compiled_prompt_file` 导演交付包，是否逐句包含台词（`source_text` 去标点）、说话人和发声方式 | 缺失则回到交付包补齐并重出 H3 成稿；都已包含但仍无声时核对原生音频能力和实际音轨，不得直接归因于字幕 |
| 视频近似静止或像幻灯片 | 视频/关键帧 | 检查分镜中的可见画面发展、摄影阶段、观察对象/焦点变化、导演交付包与 H3 成稿，以及是否无差别传入过多静态关键帧 | 补足实际缺失的画面过程或摄影意图；可由人物、环境、空间、物件、光线、焦点、遮挡或声音关系推动。若有意保持静止，核对其观看目的是否在 Prompt 中保留；关键帧只保留已确认的独立用途，按工具能力作为参考使用 |
| 已批准角色或道具设定本身错误 | 资产 | CHR/PROP 版本、需求来源和验收记录 | 建立正确的新资产版本，不覆盖旧版 |
| 生成片段中的角色、服装/装具、道具或场景漂移 | 视频 | 已批准 CHR/PROP、上一段场景锚点帧和尾帧、文字承接 | 在对话中注明文字锚点强化和可选重生范围；不伪造参考图输入 |
| 计划人声静音、漏说、类型或口型职责错误 | 视频 | `speech_mode`、speech type、逐字文本、时间窗、原生音轨和嘴部 | 在对话中给出生成 Prompt 修正建议；旁白/画外音/内心独白明确画面人物不开口 |
| 每个片段边界明显跳一次 | 分镜/视频/成片 | SEAM 合同、选定 tail FRM 与下段 `reference_inputs` 登记、动作相位、摄影机运动、光位和声音桥 | 不按文件边界直拼；用 `ffmpeg_tool.py frame --tail/--at` 选稳定切点（best available），失败则在对话中给出可选重生后段或重设分镜边界的建议，由用户决定 |
| 画面中残留模型硬字幕、随机文字或旧字幕 | 视频/成片 | 视频生成参数、播放检查、字幕擦除结果 | 先确认生成阶段已禁用字幕；片段正式交付前用 `ffmpeg_tool.py erase`（固定区域 delogo 擦除，输出新 `_vNN` 版本）擦除并以 probe/播放验证；移动或大面积文字擦不净时保留原片段，说明可见问题与可选修复范围；不自动重生。只有客观媒体无效才阻断候选展示 |
| 字幕错位、越界、遮脸或遮道具 | 成片 | 最终音轨、SRT、成片画面和安全区 | 对照成片实际口播重新对轨，并调整断句或文字位置后重新烧录或断句后烧录 |
| 工具返回成功但看不到内容 | 当前执行阶段 | 返回 ID、文件大小、实际播放/查看结果 | 不更新状态，重新取证或修复失败项 |
| 状态显示完成但文件缺失 | 控制层 | `制作状态.json`、产物清单和磁盘 | 回退状态并补齐产物 |

## 第 0 阶段：规划

| 问题 | 诊断 | 修复 |
|---|---|---|
| 一句话卖点与剧情目标无关 | 比较 `creative_proposition` 和用户目标 | 重写卖点、戏剧问题和成功定义 |
| 受众画像像刻板印象 | 检查来源状态和检索证据 | 改为待验证假设，删除人口标签推断 |
| 类型、情绪和风格互相冲突 | 检查主路径、辅助路径和排除项 | 保留一个主路径，明确辅助职责 |
| 风格只有“电影感”“高级感” | 检查 `style_contract` | 改写为光线、色彩、构图、材质和节奏机制 |
| 模型、时长或视频确认轮次不兼容 | 对照当前工具 schema 和已确认模型 | 停止调用并返回规划重新确认；用户未指定时仍固定 MiniMax H3、单 SEG 为 4–15 秒整数秒（上下限读 `tools/video/h3.json` capabilities），不得自动切换其他模型 |
| 风险只有名称没有处理方式 | 检查 `risk_plan.mitigations` | 为每项风险补缓解、确认或接受理由 |

## 剧本阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 主角被动等待 | 逐场找改变局势的选择 | 给主角目标、时限、策略和代价 |
| 场景删掉也不影响剧情 | 做删除测试 | 合并或重写该场 |
| 反转突然出现 | 反查公平线索和前置规则 | 补铺垫或删除反转 |
| 台词只解释画面 | 标记每句策略和结果 | 改为试探、逼迫、回避、反击或行动 |
| 关键声明没有证据 | 查台词证据链 | 增加可见动作、道具、结果或标记主观判断 |
| 台词在时长内说不完 | 朗读估时 | 调整场次、动作或时长，不改用户原文 |

## 分镜阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 分镜多但生成仍是长镜头 | 对照总控卡逐段执行区、十五列分镜与实际提交的 H3 成稿 | 为每镜补画面过程、切入原因、动作桥、新增信息、承接锚点和切出落点 |
| 运镜统一推近/拉远或统一固定 | 对照 `storyboard-design.md` 的运镜动机、观看关系和实际画面 | 先判断固定或移动是否服务本场观看；只修缺动机的起停与突兀承接，不为分布换运镜 |
| 镜头碎切 | 做删除测试 | 合并没有独立职责的镜头 |
| 长镜头没有内容 | 对照 `storyboard-design.md` 的一镜到底方法和 `storyboard-segments.md` 的尾态要求 | 增加连续摄影机路线、主体行动、空间变化、有效调度、焦点、信息与结果，或拆镜；不得补隐藏切点 |
| 跳轴、换手、瞬移 | 查分镜表镜内调度、轴线和动作桥 | 按“前镜状态 -> 动作发起 -> 运动路径 -> 切点/镜内调度 -> 后镜续接 -> 接触/反馈 -> 结果”修正 |
| 开头不抓人 | 先检查 `density_profile` 和首个完整叙事节拍 | 按观看顺序检查首个叙事过程中的问题、目标、关系、证据与注意力；修真实设计，不加固定事件配额 |
| 高光只有发光或慢推 | 检查高光因果链 | 回查已确认亮点如何成立，修实际缺失的因果与可见依据；反馈可共镜、延迟或留白，不为四步骤补反应镜头 |
| 结尾只是回到相似画面 | 检查结果、反应与落点 | 补完整结果和落点；只有已规划无缝 Loop 才允许回到起点构图 |
| 台词、动作在片段边界被截断 | 查绝对时间轴 | 把边界移动到真实切镜点 |

## 资产阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 三视图生成多个角色 | 查防复制声明和头部身份锚点 | 明确同一角色多个角度，只出现一个主体 |
| 三视图带笑、怒、惊讶、卖萌或异常修饰 | 查中性表情与类型分支 | 恢复无情绪状态，并按真人、动漫、卡通或动物分支定向重生 |
| 真人脸部畸变或动画/动物结构异常 | 对照 `representation_type` 查看头部特写及侧面 | 真人按正常人脸、动画按原设计、动物按物种头骨与器官结构重生 |
| 动漫、卡通或动物被错误真人化 | 核对类型策略、画风合同和数据卡身份锁 | 锁定角色类型、轮廓、颜色纹理及物种特征后重生 |
| 角色换装或毛发状态变化后身份漂移 | 查状态版本来源 | 基于已批准身份资产补实际变化所需视图；局部状态不重画全套 |
| 同一 SEG 内服装或发型突然变化 | 查 `project_data_card.json` 状态时间线和分镜变化镜头 | 无变化镜头则在对话中注明该 SEG 可选重生范围；确有剧情变化则补状态记录与对应镜头 |
| 不同集角色面部、身高体型或音色漂移 | 对照 CHR/VOICE 共享基准、数据卡身份锁和本集实际有疑点的代表帧 | 保留共享基准，在对话中注明漂移 SEG 可选重生范围；不得为本集另造角色或音色 |
| 主要场景跨集布局变化 | 对照 SCN 布局参考、数据卡场景状态和实际 tail FRM | 无剧情原因则在对话中注明可选重生范围；确有改造或时间变化则先更新状态时间线 |
| 道具结构变形、部件错位或比例失调 | 对照道具结构、部件数量、连接方式和尺寸比例 | 强化结构描述后定向重生；局部问题可限定区域做 参考生图（`img --ref`） |
| 道具材质塑料化或颜色漂移 | 检查材质、光泽、纹理、主辅色和棚拍高光 | 写具体可见材质特征并重生，不用“高级质感”等空词 |
| 道具开合、破损、发光或内容物状态错误 | 核对当前 `PROPxxx` 状态版本与总控卡逐段执行区首尾状态 | 为互斥状态建立独立版本，只修复错误状态 |
| 三视图结构不一致或内部细节不可见 | 比较正面/侧面/背面并检查细节卡需求 | 重生三视图；内部结构、刻字或机关另生成细节卡 |

## 视频阶段

下表修复列中的“可选重生范围”只作对话说明与候选展示；任何视频生成、重生或编辑调用统一适用「排障原则」第 6 条：用户明确提出并重新完成视频参数确认后才可提交。

| 缺陷 | 编号 | 诊断 | 修复 |
|---|---|---|---|
| 下一段开场与上一段实际尾帧跳变 | `F-*` | 检查衔接卡、下段 `reference_inputs` 中的 previous tail FRM、0 秒承接声明和真实输入记录 | 补齐真实尾帧与角色身份参考后，在对话中给出下一段可选重生范围；用户主动要求修改前不调用视频工具 |
| 人物服装、妆发、伤痕或随身装具跨片段不一致 | `V-*` / `F-*` | 核对当前角色状态资产、上一段 character_state 参考、previous_tail_as_start_frame、本段已规划高光 KF（若有）和真实 reference_inputs | 缺状态资产先返回资产阶段补齐；缺上一段状态帧则抽取并登记进下段 `reference_inputs`；输入齐全仍漂移时在对话中注明后段可选重生或相关 KF 修正范围 |
| 复现道具形状、归属、可见面或开合破损状态跳变 | `V-*` / `F-*` | 核对 PROP 状态资产、上一段尾帧/场景锚点图、接缝卡道具接触和本段 Prompt | 缺道具资产先补资产；缺状态参考先用 `ffmpeg_tool.py frame` 补提取并登记进下段 `reference_inputs`；接触关系错误则修分镜接缝或在对话中注明责任片段可选重生范围 |
| 输入素材过多、模型随机取舍 | `V-*` | 查参考素材预算和必需图片优先级 | `continuous` 接缝保留上一段 tail FRM；`elliptical` 从新起点资产开始。再按当前角色状态、本段高光 KF（若有）、当前场景、关键/复现道具和风格选最小充分集；仍超限则拆段或确认降级 |
| 未经本次视频参数确认就准备生成，或用户只是抱怨/纠正却触发生成 | `C-*` | 查最近用户意图、按 `interaction-ask-video-clarification-ref.md` 展示的完整参数、AskUserQuestion 执行确认结果、`generation_confirmation_id` 与工具调用时间 | 立即停止调用；若已有任务在生成中，等待结果并如实说明；只有用户明确提出创作/修改需求后，按确认 ref 重新列完整视频参数并通过 AskUserQuestion 取得执行确认 |
| 上一个视频仍在生成中又准备提交新视频 | `C-*` | 查当前工具任务状态、上一段保存/交付记录和新视频是否已被当前确认覆盖 | 未被当前确认覆盖时回复“上一个视频正在生成中，请耐心等待结果出来后再调整”；明确要求新任务时先按 `interaction-ask-video-clarification-ref.md` 重新做视频参数确认，确认后才生成 |
| 确认采用的 VOICE 修复音频声线变化 | `A-*` | 查 VOICE ID、版本和修复范围 | 局部修复始终复用同一已批准 VOICE 资产，不替换合格原生人声 |
| 身份漂移、复制人、随机文字 | `V-*` | 播放检查、已批准 CHR/PROP 与文字锚点 | 设定正确时在对话中注明文字锚点强化和可选重生范围；设定本身错误才返回资产 |
| 原生声线跨片段变化 | `A-*` | 逐段试听原生音轨，核对声音主体、情绪和发声描述 | 在对话中注明统一发声描述和可选重生范围；不得用 VOICE 资产冒充当前视频输入 |
| 静音、漏说、串角色、类型错误或口型错位 | `A-*` | 播放原生音轨，核对声音主体、type、逐字文本、时间窗和嘴部职责 | 在对话中给出 `speech_mode`、`speech_lines` 与发声描述修正建议 |
| 构图跳变、动作回弹、声音桥断 | `F-*` | 对比上段 tail FRM 与下段 0 秒画面、动作向量、摄影机运动、光位和音频 | 调整实际剪切点；在对话中给出动作/遮挡/甩镜匹配或声音桥修正建议，由用户决定是否返修 |
| tail FRM 与 KF 核心状态偏离 | `V-*` / `F-*` | 对比相关高光 KF 与实际 tail FRM，定位身份、构图、状态或动作相位差异 | 核心因果或连续性受损时在对话中给出 SEG 可选重生范围；仅审美轻微差异可保留为候选；accepted 仍取决于真实用户接受 |
| 镜头遗漏、单过程拖时、摄影意图同质 | `S-*` | 对照 shot_plan 逐镜检查计划/实际画面过程、摄影阶段及观察对象 | 修 Prompt 并核对导演意图是否完整保留；实际仍退化为单一推拉时返回分镜重做观看设计 |
| 因果断裂、钩子未兑现 | `N-*` | 对照规划、剧本和分镜 | 返回最早叙事错误层级 |

## 成片阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 接缝硬跳 | 先按正常速度观看有疑点的边界；需要定位才定向慢放或取帧 | 按已冻结内容区间拼接；先核下段 `reference_inputs` 的真实tail FRM与时间码。新剪点不追溯改写已生成请求的输入记录，影响连续后段时按真实依赖提出返修；连续性问题作为返修建议告知用户，不阻断交付 |
| 音量忽大忽小 | 探测人声、环境声和 BGM 响度 | 分轨混音与响度归一 |
| 客观检查不过 | 查看 probe stdout 与 lint 报错的具体项 | 按错误修复媒体或 SRT，重新 probe/播放验证 |
| 字幕与台词稿疑似不符 | 对比 alignment 的时间范围、expected_text 和实际字幕正文 | 定向试听成片；字幕正文仍取 source_text 的去标点派生，确认是否需要修改 |
| 字幕出现整句缺失或无效时码 | 对照 script_contract、字幕初稿和最终音轨 | 重新整理台词稿并人工复核；若确认源音轨缺失，关键已确认台词缺失记录返修建议并告知用户，由其决定是否返修 |
| 字幕与发声不同步 | 比较最终音轨、字幕时间轴和 SRT | 对照最终音轨重新校核字幕起止时间 |
| 字幕越界或遮挡 | 查看最长行、换行、边缘位置或遮挡等实际风险帧；不逐条固定抽三帧 | 优先调整断句或 `ffmpeg_tool burn` 的位置参数并重新烧录 |
| 修完局部又出现新问题 | 重新检查实际成片与受影响内容 | 内容问题在对话中给出观察与返修建议并向用户说明（`blocked` 只用于客观检查失败），不能只凭可播放代替人工审看；重新生成仍需生成确认 |

## 工具、状态与部分成功

- 工具不存在：停止受影响步骤，说明具体缺口和可选处理；技术排障或用户询问时可解释必要工具信息。不得假称已生成或静默换工具。
- 内部结构、校验或配置缺口：在不改变已确认内容、输入、模型和授权的前提下修复并复验；无法满足合同则停止受影响步骤，说明对可见产物的影响。不得通过降级、丢弃输入或放宽检查继续生产。
- 工具路由错误：先逐张盘点真实媒体输入；图片生成在无有效视觉参考维度时使用 文生图（`img`），有相关身份、结构、空间、构图、媒介或画风参考时使用 参考生图（`img --ref`）。视频模式、参考使用方式和成稿必须实际调用 `h3-prompt-writing` 决定，不按媒体种类自行推断。`continuous` 非首段保留选定出点对应的真实 tail FRM（帧文件与时间码登记在下段 `reference_inputs`）；`elliptical` 按新起点实际需要提供输入。已批准 VOICE wav 在 Ref2VA 模式是必传音色参考（台词声部有 approved 样音而不传即 `voice_audio_input_missing` 硬错），不要求同时提供真实视频；仅非音频模式或该声部无 approved 样音时保留同一 `voice_anchor` 文字锚点，不伪造媒体。修改已有视频时提供真实源视频和保留人声、音色、口型等修改边界。技术不兼容交回 H3 Skill，导演信息不足返回上游；重新生成前重新冻结请求快照并按原视频确认流程重新确认。
- 视频重生成（`h3`） 输出时长或比例变化：判定编辑失败，保留源视频并标记需重新编辑；确需改变时长或比例时返回分镜/成片建立新版本，不放宽编辑合同。重新编辑前必须按 `interaction-ask-video-clarification-ref.md` 重新完成视频参数确认。
- 缺少有效 `drama_plan.json` 或规划确认：保留现有文件，核实来源和当前缺项；完成符合当前合同的规划后，展示完整参数表并按既有 planning 确认流程继续，不推断授权。
- 参数 schema 不确定：读取实际 schema，不从其他工具类比参数。
- 模型不兼容或生成失败：不得以提高质量、延长片段或节省重试为由自主换模型；当前本地只有 MiniMax H3 与 gpt-image（知脑中转），换模型必须经用户明确选择并重新确认完整参数。
- 调用超时：先检查返回 ID、任务状态和文件，不立即重复调用。
- 部分成功：保存成功项及版本，只补失败项；涉及视频生成、重生或编辑的失败项只记录返修范围，重新调用前必须按 `interaction-ask-video-clarification-ref.md` 重新完成视频参数确认。
- 本地大改：先写同目录临时文件，验证后原子替换，成功再清理。
- 状态更新：产物实际验证通过后才递增 revision 和提交阶段状态。

## 排障结束条件

按任务目标核实以下事项；诊断已完成、候选已交付且用户尚未要求返修时，可以报告结论并结束，不强制生成新媒体：

- 根因归属到明确阶段和稳定 ID。
- 实际执行的修复已落盘；仅诊断时写清原因与可选范围，不虚构修复版本。
- 自动结构检查通过。
- 图片已目视、音频可试听、视频具备可渲染/可播放资源并已实际观看；内容观察已记录并向用户说明，内容问题不阻断交付，返修由用户主动提出。
- 缺陷记录包含证据和复验结论。
- 已发生上游修改时标明实际受影响下游；重新生成仍须其授权，诊断本身不使未变产物失效。

恢复按已确认源版本、duration_contract 真实来源、当前内容核算、请求快照、媒体实测与最新有效确认定位。文件须满足对应产物的必需字段、引用和内容合同；缺项时保留原文件并报告，禁止猜测补齐。按实际依赖失效，不全项目盲目重审。
