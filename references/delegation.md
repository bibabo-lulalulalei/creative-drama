# 执行委派 Ref

主 Agent 负责创作决定、用户确认和交付。视频生成及成片工具可由主 Agent 直接运行；单条 CLI 不建立子代理交接包。

## 可选委派

仅当有多个输入就绪、互不依赖的媒体任务，或委派能释放主对话等待时使用 subagent。委派不改变当前集范围、真实生成授权或输出版本。

交接只包含：项目根、当前集与 SEG、已授权的完整命令、允许输出路径，以及“不得修改上游、Prompt、模型、请求或授权；失败原样回报”。执行者读取命令需要的文件即可，不复制整套 Skill、上游合同、禁止事项或额外 JSON。

视频工具已负责授权与输入绑定、任务持久化、轮询、文件有效性和 candidate 登记；执行者返回工具结果，主 Agent 直接展示视频路径，不重复跑同一套检查。成片工具按锁定剪辑策略执行，最终内容审看仍由主 Agent 负责。

## 依赖与收口

- 需要上一段真实尾帧的 continuous 链按依赖顺序执行；取得并选定尾帧后才能准备下段。
- 同批无尾帧依赖且已确认的片段可依次 --submit-only，再逐项 --resume；远端可并行计算，本地不同时写同一 manifest。
- 确认只由主 Agent 向用户取得；执行者不换模型、不重写内容、不自动重生、不再次委派。
- 用户目标、逐集闭环和实际生成授权保持有效；成功产物及时给出路径，失败只恢复受影响任务。
