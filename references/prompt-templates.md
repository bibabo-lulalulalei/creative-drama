# 资产 Prompt 模板

按资产类别读取所需模板；字段、枚举和登记结构以 `references/manifests/` 对应分册为准。模板只给固定结构，方括号内容按当前已确认事实填写；Prompt 正文保存到项目文件，并通过 `--prompt-file` 提交。

## 角色三视图

基准三视图 Prompt 必须包含以下中性表情共通句，并且只追加一个符合 `representation_type` 的头面结构分支：

```text
表情状态中性，无任何情绪表演：头面相关肌肉与结构自然放松，双眼自然睁开并直视前方，嘴、喙或口部自然闭合；不微笑、不皱眉、不龇牙、不吐舌、不瞪眼，不表现愤怒、悲伤、惊讶、恐惧、轻蔑、挑逗、卖萌或其他情绪。
```

```text
真人/写实人物：面部结构正常自然，五官比例可信，眼球、瞳孔、鼻、嘴唇、牙齿、耳朵和下颌无畸变，保留真实肤质，无塑料脸、蜡像脸或过度磨皮。
```

```text
动漫/卡通人形：头面结构符合已确认角色设计与画风，正面和侧面的五官位置可互相对应，无非设计性的错位、重复、缺失或左右漂移，不擅自真人化。
```

```text
拟人动物/自然动物/其他生物：头面结构符合已确认物种或生物设定，眼睛数量、瞳孔、耳朵、角、口鼻或喙、牙齿及头骨关系正确，无额外器官、错位、粘连或非设定的人脸化。
```

妆容或表面修饰按类型选择：真人使用无妆或自然日常妆；动漫/卡通保持干净基础妆面或原始设计；动物默认无人体妆容，只描述毛色、羽色、鳞片、斑纹和已确认装饰。

```text
【类型、风格与用途】角色表现类型为[representation_type]，[已确认的全局风格机制]，用于锁定角色身份与造型的角色设定图。

【版式与身份一致】纯白中性背景。左侧 1/3 区域为超大高清正面头部特写，角色正对镜头，头部端正，不偏转、不低头、不抬头，头面占左侧区域约 80%。右侧 2/3 区域横向整齐排列同一角色的全身正面、严格 90 度侧面、背面三视图；三个角度等大对齐，最高点和最低接地点基线一致，从头到脚以及翼、尾、角、耳等附属结构完整入画。右侧正面头部与左侧特写完全一致；三个角度保持同一头面结构、颜色纹理、体型、毛发/发型、服装/装具和标志性特征。该图展示同一角色的多个角度，不是多个角色。

【体态与肢体】[按角色类型填写生命阶段、性别表达、身高或相对尺度、体型、头身比或物种比例、肩宽、腰线、四肢比例、自然姿态、重心、肢体与关节]；[人形角色填写手指，动物填写爪、蹄、翼、尾等物种结构]。

【头面结构与中性表情】[逐字粘贴本节中性表情共通句，以及与 representation_type 对应的结构分支，不得改写]。

【毛发、妆容与识别特征】[按类型填写发型，或毛、羽、鳞和斑纹]；[按类型填写无妆、自然日常妆、基础动画妆面或无人体妆容]；[饰品、角、耳、尾、痣、疤痕等特征的位置和大小，无则明确写无]。

【服装、装具与材质】[有服装或装具时写款式、颜色、内外层顺序、领口、肩线、衣长、袖长、袖口、腰封/腰带、裙摆/裤脚/鞋履、扣具/绑带等可数部件、长度和穿戴关系；无则明确写无]；[服装材质或身体表面的肤质、线稿、色块、毛羽鳞甲纹理、褶皱、反光、磨损位置和状态]。

【棚拍光与画面纯净】均匀柔和棚拍光，主光与补光平衡，阴影极淡且方向一致，角色轮廓清晰，无环境色反射；材质表现符合已确认画风，画面纯净，无任何文字、水印、logo 或无关物体。
```

## 道具资产图

```text
【风格、模式与用途】[已确认的全局风格机制]，[关键道具三视图/普通道具主视图/局部细节卡]；[道具名称、类型、剧情用途和叙事意义]。

【版式与一致性】[三视图：纯白或中性深灰背景，横向三等分排列，从左到右依次为正面、严格 90 度侧面、背面；三个角度等大对齐、居中、完整不裁切，保持同一尺寸、结构、材质、颜色、磨损和识别特征。/多状态图：纯白或中性深灰背景，按从左到右或从上到下分区展示同一道具的多个状态，每区只放该道具的一种状态，状态顺序与 state_timeline 一致，状态之间结构差异清楚可见。/主视图：纯白或中性深灰背景，选择最能说明结构的观察角度，道具居中，约占画面 60%，完整不裁切。/细节卡：只展示指定部件及其与主体的连接关系。]

【尺寸与整体结构】[整体尺寸或相对尺度、长宽高比例、边角形态、主要组成部分、连接和开合方式]。

【部件与空间关系】[逐个写关键部件的数量、形状、位置、朝向、连接关系和当前状态]。

【材质、纹理与颜色】[各部件材质、表面处理、光泽、纹理、主辅色及磨损老化状态]。

【使用状态与识别特征】[当前状态及其可见证据；多状态图要逐区写清 STATE001、STATE002、STATE003 各自的开合、破损、点亮、内容物、归属、可见面和剧情触发]；[剧情确认的刻字、图案、特殊结构或内容物的位置和状态，无则明确写无]。

【棚拍光与画面纯净】均匀棚拍光，阴影淡且方向一致，轮廓边缘清楚；金属、玻璃、塑料等反光材质保留与材质相符的自然高光带，所有纹理与使用痕迹清晰可见。除已确认的道具原生刻字或图案外，无随机文字、水印、logo 或无关物体。
```
