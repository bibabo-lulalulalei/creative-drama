# 题材受众库 Reference

> 本文件只提供受众、平台和题材假设。规划或剧本需要形成、校准受众/平台/题材假设时，读取对应章节；用户未明确时用于形成可确认的默认假设，用户已明确时只用于深化和校准对应方向，不因进入阶段就整库读取。不得把市场倾向、人口画像或平台偏好伪装成实时事实。

## 本 Ref 关键要求

- 用户明确设定优先；未确认的受众、平台和题材判断只能写成可修改假设。
- 涉及最新趋势、审核、平台规则或市场偏好时必须检索可靠来源并记录日期。
- 受众机制只用于解释情绪需求，不得按年龄、地域或性别机械决定角色和结局。
- 平台适配不能擅自改变字幕策略、BGM、水印、模型或阶段流程。

## 使用合同

- 用户明确设定优先；涉及“最新、热门、审核、平台规则、市场偏好”时必须检索官方或可靠来源，并记录日期。
- 画像、地区差异和情绪曲线只用于提出假设，不按性别、地域或年龄决定角色、结局和价值观；没有研究支持时不做效果排名或付费意愿推断。
- 钩子、情绪、反转和爽点密度按题材、总时长和人物因果动态决定，不执行固定 `3 秒`、`15 秒`、`3:1` 或 `80-100 集`模板。
- 平台可能影响比例、展示位和安全区，但不能擅自改变项目字幕策略、自动添加热门 BGM 或水印；本 Skill 默认不加字幕，只有用户明确要求字幕时才按 `delivery.md` 生成无标点 SRT，并使用本地 `ffmpeg_tool burn` 烧录。
- 本文件不是法律意见或平台审核规则。敏感内容遵守当前平台政策、适用法律和宿主安全规范，不能用“改名影射”规避事实或合规责任。

## 一、受众心理八大底层机制

观众需求可以用下列机制形成可检验假设。一部作品不必同时触发多种机制，数量不代表质量；应选择与人物、类型承诺和结局一致的最小组合。

| 机制 | 可能的触发方式 | 可讨论的题材 |
|---|---|---|
| **代偿满足** | 角色完成观众想做而未能做的选择 | 逆袭、复仇、职场、重生 |
| **代入认同** | 具体处境与生活经验让人理解角色 | 职场、家庭、校园、社会现实 |
| **信息领先** | 观众知道角色尚不知道的事，形成期待、焦虑或戏剧反讽 | 喜剧、悬疑、身份、智斗 |
| **情感宣泄** | 事件与关系的累积使情绪释放具有分量 | 情感、家庭、励志、悲剧 |
| **认知好奇** | 一个值得理解的问题及可追踪线索 | 悬疑、推理、科幻、高概念 |
| **讨论与分享** | 具体选择、形式或议题带来不同解释 | 社会议题、关系、形式实验 |
| **审美愉悦** | 声画、表演和时间体验具有吸引力 | 各题材均可 |
| **安全感/陪伴** | 熟悉的人物与相处方式形成持续连接 | 日常、治愈、情景喜剧 |

### 机制组合公式

| 组合 | 触发机制 | 可测试的目标 | 题材候选 |
|---|---|---|---|
| **掌控感组合** | 代偿满足 + 代入认同 + 信息领先 | 选择和能力兑现；缺乏前因时会像开挂 | 逆袭、身份、复仇 |
| **情感组合** | 代入认同 + 情感宣泄 + 陪伴 | 连接与共鸣；过度指定反应会煽情 | 家庭、治愈、关系 |
| **推断组合** | 认知好奇 + 信息领先 + 讨论 | 推断与重释；线索不公平会损害信任 | 推理、高概念 |
| **讨论组合** | 讨论与分享 + 认知好奇 | 多种可理解立场；无具体人物则会空泛 | 社会议题、话题剧 |

## 二、短剧向题材——两大维度

部分商业短剧以爽感释放为主要回报，也有悬疑、喜剧、惊悚、治愈、悲剧、儿童、社会现实和实验表达。以下“个人掌控/群体认同”只是一组爽感题材分析轴，不代表全部短剧。

### 2.1 个人主义爽感（打破规则、掌控命运、极致自我）

**核心心理**："我"的意志、能力和情感欲望的彻底释放。
**可能受众假设**：偏好个人选择、能力兑现或规则突破的观众；具体平台与地域分布必须另行验证。

| 题材 | 核心爽点 | 写作要点（怎么做） |
|---|---|---|
| **重生/预知/无限流** | 利用信息差降维打击，弥补遗憾 | ①信息差要清晰 ②弥补遗憾要有情感重量 ③循环/预知要有规则和限制 ④每次重生要有新发现 |
| **穿越/异世界** | 用现代知识/科技在古代/魔法世界享受智商优越感 | ①文化反差是重要笑点来源 ②现代知识用在关键处 ③异世界规则要清晰 ④主角不能无所不能 |
| **末世囤货/生存基建** | 在秩序崩塌的世界享受绝对安全感和"别人挨饿我吃火锅"的优越感 | ①囤货清单要具体（越具体越有满足感） ②末世残酷和主角富足形成强烈对比 ③不能只有囤货没有冲突 ④基建/种田要有进度感 |
| **狼人/天选伴侣** | 宿命关系与个人选择的冲突 | 先明确同意、规则与选择权，不把命定关系等同于占有；具体市场表现另行核验 |
| **吸血鬼/黑帮关系** | 危险身份与亲密需求的张力 | 双方均有主体性，区分角色魅力与对控制、暴力的认可；不以“海外”推断偏好 |
| **系统/修仙升级流** | 从弱者一路升级变强的成长快感 | ①升级要有视觉化呈现 ②金手指要有特色不是普通系统 ③爽点分层（小爽/中爽/大爽） ④升级要有代价 ⑤主角要有执念和软肋不是升级机器 |

### 2.2 集体主义爽感（阶层跃迁、打脸围观、重塑秩序）

**可用心理假设**：尊重、归属与公共评价，回报可通过资源、权利和相处方式体现，不必靠围观震惊或跪拜。
**可能受众假设**：重视身份确认、家庭/群体关系或公共评价的观众；不得用地域标签直接推断。

| 题材 | 核心爽点 | 写作要点（怎么做） |
|---|---|---|
| **掉马甲/隐世身份** | 身份被重新理解，改变真实筹码 | 隐瞒有动机，揭示有前因，后果落到资源和关系；不按羞辱程度决定爽感，不强加震惊、悔恨或跪拜 |
| **真假千金/豪门上位** | 通过血缘或联姻进入最高权力结构 | ①豪门规则和阶层差异要清晰 ②女主能力要具体不是突然变强 ③假千金/反派的恶要具体 ④不能只有宅斗没有成长 |
| **年代/四合院/年代知青** | 在复杂邻里和家族纠纷中斗倒极品亲戚 | ①年代细节要真实（粮票/工分/大锅饭） ②极品亲戚的恶要具体（占便宜/说闲话/使绊子） ③主角智慧要符合年代 ④不能只有斗极品没有生活感 |
| **婆媳伦理/手撕极品亲戚** | 聚焦中国式家庭结构性压迫，从被压迫到反击 | ①家庭压迫细节要真实（具体台词/行为/场景） ②主角反击要有逻辑（从隐忍到觉醒的过程） ③不能只有撕没有情（亲情和利益的拉扯） ④结局可以是切割也可以是和解（但和解要有前提） |
| **萌宝/天才儿童** | 单亲妈妈带天才宝宝，宝宝神助攻 | ①萌宝可爱要具体（语言/动作/表情） ②萌宝聪明要符合年龄（不能太成人化） ③女主成长要和宝宝相关 ④不能只有萌宝没有剧情 |
| **衣锦还乡/家族正名** | 为受辱的父母报仇，让整个家族获得尊重 | ①当年屈辱要具体 ②还乡排场要到位 ③不能只有打脸没有情感（对家乡的复杂感情） ④家乡人转变要有层次（不是所有人都立刻变脸） |

## 三、微电影向题材——四大类型

微电影/短片同样可以是喜剧、惊悚、动作或爽感故事。下表只列关系与议题方向的候选，不定义全部短片的核心。

| 类型 | 核心价值 | 代表方向 | 写作要点（怎么做） |
|---|---|---|---|
| **情感共鸣型** | 理解具体的人与关系 | 离别、重逢、和解、独处 | 从相处方式和正在做的事写情感；直说、沉默和物件都可用，不预定哪一种更有力量，不强求和解 |
| **治愈自愈型** | 在平凡日常中找回小确幸 | 深夜食堂、辞职返乡/GAP、一日限定关系、独居美学、宠物告别 | ①主角烦恼要"小而真实"（孤独/迷茫/不自信） ②用"细节"传递温暖（一杯热饮/一把伞/一盏灯） ③不要美化逃离（新生活也有新困难） ④结尾可以"不解决问题但给希望" |
| **社会议题型** | 看见现实处境中的具体选择 | 工作、教育、照护、代际、技术与生活 | 基于可靠事实和人物经验，不预定系统或个人谁必须是反派；结尾可回答、追问或保持复杂，不硬补温暖 |
| **品牌/商业微电影型** | 已授权剧情中的品牌职责 | 家庭、工作、生活服务等剧情 | 先有成立的故事再处理商业信息；产品作用与片尾文案按用户已确认目的决定，纯品牌 TVC 仍在本 Skill 范围外 |

## 四、国内 vs 海外受众差异

以下按观看需求比较，不对应国家或地区分组；同一人也可能在不同作品中选择不同体验。地区差异须有当前资料支持。

| 维度 | 群体认同导向假设 | 个体成长导向假设 | 强个人选择导向假设 |
|---|---|---|---|
| **核心回报** | 被尊重、关系重排、群体确认 | 自我定义、能力成长、边界建立 | 自由选择、承担代价、掌控命运 |
| **对规则态度** | 渴望在规则内成功（升职/发财/被认可） | 渴望打破规则+做自己 | 渴望打破规则+反抗权威 |
| **家庭观念** | 家庭是核心，家族荣誉重要 | 家庭重要但个人也重要 | 个人是核心，家庭可以是束缚 |
| **情感表达** | 可能关注关系责任和共同经历 | 可能关注自我表达和边界 | 可能关注自主决定；表达方式仍由具体人物决定 |
| **对立面期待（待验证）** | 可能偏好明确后果 | 可接受灰度与关系代价 | 可接受复杂立场和非胜负式结局 |
| **结局期待（待验证）** | 可能偏好明确回报 | 成长、闭环或开放均可 | 重视选择后果，喜悲结局均可能成立 |
| **节奏期待（待验证）** | 可能偏快 | 可允许情感沉淀 | 可允许更多角色发展；仍须按平台与项目验证 |
| **亲密表达（待验证）** | 可能偏行动与关系责任 | 行动和语言并用 | 可能更直接；仍须服从角色、分级与平台规则 |

### 出海内容本土化建议

以下仅是本地化核验问题，不是对“海外观众”的统一结论；必须结合目标国家、语言、平台、分级与当前可靠资料逐项验证：

1. **文化语境可理解性**：检查"赘婿""婆媳""四合院""知青"等概念是否需要保留、解释或转译，不默认删除。
2. **个人与群体价值权重**：验证目标受众更关注个人选择、家庭责任还是群体秩序，不预设单一价值观。
3. **亲密关系表达**：依据题材、分级和受众证据决定身体吸引力与情感张力的表达尺度。
4. **人物灰度接受度**：验证目标市场对不完美主角、复杂反派和开放结局的接受范围。
5. **节奏与信息密度**：按平台、类型和样本验证，不把“海外”直接等同于快节奏或慢节奏。

## 六、情绪曲线设计——六种经典曲线

根据受众和题材选择合适的情绪曲线。

| 曲线类型 | 适用受众/题材 | 设计要点（怎么做） |
|---|---|---|
| **爽剧型（先抑后扬）** | 爽剧受众 | 尽早建立冲突；压力与释放交替；回报逐级升级；连续剧结尾可留钩子；不设固定秒数和比例 |
| **甜宠型（温暖持续）** | 寻求浪漫与亲密体验的观众 | 关系靠近有具体原因，冲突不靠机械误会与补糖；结尾可停在日常，不强求钩子 |
| **悬疑型（持续紧张）** | 悬疑受众 | 开头建立谜团；按推理需要释放公平线索；中段改变判断；结尾兑现当前问题并按需建立更大问题 |
| **虐心型（持续压抑最后爆发）** | 接受悲剧与复杂情感体验的观众 | 代价来自具体选择与处境，不靠不断加伤害；情绪可以爆发、压住或延迟，结局按作品承诺 |
| **治愈型（平缓温暖）** | 都市青年、治愈系爱好者、疲惫的打工人 | ①整体基调平缓温暖，没有大的情绪波动 ②用日常细节和小温暖打动观众 ③可以有淡淡的忧伤但底色是温暖的 ④节奏慢，允许有留白和沉默 ⑤结尾是治愈的，给观众温暖和力量 |
| **反转型（预期被重释）** | 反转与推理受众 | 开头建立默认认知；通过公平线索逐步重释；高潮层级服务认知重释与人物行动；反转必须改变人物选择并留下后果 |

### 四个核心画像参考（含各画像钩子差异）

以下按观看需要提出假设，不对应人口群体，也不推断付费意愿。钩子方法见 `题材亮点与传播库.md`，本表只说明可能的关注差异。

| 观看需求假设 | 可能关注 | 开场候选 | 需要验证或避免 |
|---|---|---|---|
| **关系与尊重** | 照护、家庭责任、边界与被理解 | 一次具体分工或称呼中的矛盾 | 不把某年龄或性别默认写成受辱者 |
| **自主与能力** | 选择权、职业判断与能力兑现 | 一个任务里的难以兼顾的选择 | 不用突然收购、隐藏身份代替实际能力 |
| **推断与发现** | 线索、公平误导与规则 | 有依据但尚不能解释的事实 | 不把观众当作只接受简单谜题的群体 |
| **亲密与冒险** | 吸引、风险、信任与共同经历 | 两人需求冲突却必须合作 | 文化、分级和同意需具体判断，不由地区标签推定 |

## 八、不同受众的钩子设计差异

同一开场可分别测试观众是否理解人物所求、是否在意未决问题、是否愿意继续观察。依据用户研究或当前反馈调整信息前提和承诺，不将“年轻”“中老年”或平台名直接转换为前卫程度、理解能力和固定结局。

### 钩子设计的通用公式

钩子没有保证有效的通用算式。可从一个值得关心的人、一个可理解的未决问题、一种有吸引力的关系或声画体验进入；细节要属于当前处境，不为吸引力硬加极端伤害、数字、羞辱和隐藏身份。兑现方式与实际类型承诺一致即可。

## 九、内容风险与合规核验

平台规则和法律要求会变化。创作阶段先识别风险，实际发布前再依据目标平台最新官方规则核验；不得把下表当作穷尽清单或法律结论。

| 红线类型 | 容易踩的内容 | 规避方法 |
|---|---|---|
| **政治与公共事件** | 未核实陈述、冒充新闻、影射真实人物或事件 | 核实事实、来源与授权；虚构组织必须清楚标明虚构且不与真实对象混淆 |
| **暴力血腥** | 可模仿的伤害方法、猎奇伤口、虐杀或酷刑细节 | 只保留剧情必要信息，避免操作性细节和美化；按目标平台最新分级或政策处理 |
| **性与性暴力** | 露骨性内容、缺乏同意、把性暴力当刺激装饰 | 保持叙事必要性、尊重同意与受害者，不呈现可模仿细节；按受众年龄和平台规则处理 |
| **宗教、民俗与超自然** | 将现实群体污名化，或把虚构设定伪装成真实结论 | 明确世界观与虚构边界，尊重真实文化；需要事实判断时检索可靠来源 |
| **行为后果** | 把伤害、欺骗、违法或歧视包装成无需代价的成功捷径 | 展示行为对人物和关系的真实后果；结局不必统一惩罚或说教 |
| **真实人物/品牌** | 未核实陈述、仿冒、诽谤、未经授权使用身份或标识 | 核实事实与授权；虚构设定必须真正独立，不用近似名称规避责任 |
| **未成年人** | 性化、剥削、过度暴力或不适龄内容 | 采用年龄适宜表达，避免性化和伤害细节，优先保护未成年人权益 |
| **毒品/赌博** | 可操作的方法、招募引流或美化获利 | 不提供操作性细节，不鼓励、不美化，并展示必要的现实风险和后果 |
| **自杀/自残** | 方法细节、浪漫化、鼓励或模仿性表达 | 不描述方法，不美化；聚焦求助、支持、恢复或对周围人的真实影响 |

### 审核安全的通用原则

1. 对暴力、性、自伤、毒品、赌博和未成年人等高风险内容，不提供可模仿的详细方法，不美化伤害，并保持叙事必要性。
2. 真实人物、品牌、地点、事件和平台政策必须核实；需要授权时先取得授权。
3. 角色可以灰度、失败或违法，但故事要清楚展示行为后果，不能把平台偏好伪装成普遍道德定律。
4. 结局服从主题与人物选择，不强制 HE、大团圆或“坏人必须受惩罚”；目标平台有明确要求时按最新规则处理。
5. 不确定时标记待核实并停止发布决策，不能靠改名、影射或模糊表达规避核验。
