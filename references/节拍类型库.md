# 节拍类型库（beat_type 分类学与节奏参数权威）
library_version: 2

本库是 doubao-creative-drama 节奏系统的唯一人类权威：§2/§4 定义 beat_type（镜头节拍类型）分类学、基准时长区间与强度锚点；§3 定义风格节奏档案及其校准；§5 固化节奏参数。生成器只解析文件头版本行、§3 末尾机器表、§4 机读映射表与 §5 节奏参数表；其余章节为给人（LLM 导演）读的散文。散文与机器表不一致时，以机器表为准并视为事故修复散文。

---

## §1 使用规则

### beat_type 是什么

`beat_type` 是**单镜执行标注**：它回答「这一个镜头在因果链里承担什么叙事功能」，并据此给出该镜的基准时长区间。它与段级 `density_profile` **正交**——`density_profile` 决定一个 SEG 的整体剪辑形态（高密度快切、对白情感、悬疑蓄力、生活流等），`beat_type` 决定段内每一镜各自的时长档位。同一段内允许（且通常应该）混合多种 beat_type；整段只贴一种 beat_type 是节奏单一化风险信号。

### 选类流程

先问「**本镜的叙事功能是什么**」，再查 §2 总表选类，最后才看时长。禁止反过来：先定一个想要的时长，再找区间能装下它的类型贴上。判断功能时按因果链提问：

1. 这镜让观众**知道**了什么新东西（信息类：exposition / exposition_managed / plant_setup / twist_reveal / suspense_reveal / red_herring）？
2. 这镜让观众**感到**了什么（情绪类：dread_build / scare_climax / emotional_aftermath / silent_beat / tension_beat / defeat_beat / comic_beat）？
3. 这镜让局势**推进**了什么（行动类：action_chase / action_exchange / chase_escalation / negotiation / standoff / time_compression）？
4. 这镜只是**承载**别的东西（结构类：opening_hook / transition / establishing / reaction_listen / reaction_closeup / contemplation / ritual / confession / payoff）？

一镜一事：一个镜头只承担一个功能。若一镜看似身兼两职，问「压缩掉哪个功能这镜就先坏」，保住的那个是它的 beat_type。

### 三层生效区间优先级

同一 beat_type 的时长区间按以下优先级取生效值，上层覆盖下层：

1. **本集声明 overrides**：导演总控卡或分镜 JSON 中对本集特定 beat_type 的显式区间声明；
2. **风格档案**：§3 机器表中「风格 × 节拍」组合的校准区间；
3. **本库默认值**：§2/§4 的基准区间。

未命中前两层时落回本库默认。三层之外不允许第四套私设区间；确需破例（如留扣式收尾、一镜到底长镜）走 skill 既有的例外登记路径，不改区间。

### 参照系声明

本库全部基准时长区间以 **60–180 秒短剧单集** 为参照系：即一集总时长在一到三分钟的竖屏/横屏 AI 生成短剧，单镜受全局硬边界 0.8–8.0 秒约束（见 §5 `shot_bounds`）。长片语境的同类节拍普遍更长（如长片蓄压段常见数十秒），移植到本参照系时已按短剧注意力预算压缩；反之，把本库区间直接套用到十分钟以上内容会系统性偏短。

### 强度缩放

每类给出强度 1 / 3 / 5 三个锚点值，强度 2、4 及小数强度由相邻锚点**分段线性插值**得到。锚点的单调方向由数值本身表达：蓄压类（dread_build、suspense_reveal 等）强度越高越长，惊吓/切口类（scare_climax、comic_beat、action_exchange 等）强度越高越短。示例：`suspense_reveal` 锚点 4.0 / 6.0 / 8.0，强度 4 落在 6.0 与 8.0 的中点 7.0s（数值仅演示格式）。

### 禁项

1. **不得取区间中值作默认值**。中值只是锚点 3 碰巧落在几何中点时的巧合；赋值必须来自强度锚点插值，并经由相邻镜对比微调，使每镜能回答「为什么是这个时长」。
2. **不得为凑类型硬贴标签**。beat_type 是描述性的不是配额的；不存在「每段必须凑够 N 种类型」的要求。
3. **无合适类型时留空**。没有任何一类贴合本镜功能时，`beat_type` 留空，时长改由段级 intensity 序列与节奏极值锚定流程推导，事后在分镜说明里写一句推导依据。留空优于错贴。

## §2 beat_type 总表

共 30 类。前 8 类为 lint 现有合同（id 与默认区间冻结，不得改）；后 22 类为本库扩展。每类字段固定：id、中文名、定义、叙事功能、基准时长区间、强度缩放规则、典型风格、不适用反例。所有区间为 60–180 秒短剧参照系下的单镜秒数，含全局计划时长范围 0.8–8.0 秒；超过 5.0 秒会提示检查镜内发展或有意停留，但不自动要求拆镜（见 §5 `shot_bounds.info_injection_threshold_s`）。

### opening_hook 开场钩子

- id：`opening_hook`
- 中文名：开场钩子
- 定义：集首用最短时间制造「必须看下去」的问题、冲突或奇观的镜头。
- 叙事功能：在平台滑走决策窗口内建立观看契约——抛出未闭合的因果缺口（反常画面、对峙中景、后果先行），不解释、只欠账。
- 基准时长区间：0.8–3.0 秒
- 强度缩放规则：1→3.0s / 3→1.8s / 5→0.8s（强度越高越短：钩子越尖锐，切口越要抢在观众预判之前）。
- 典型风格：平台信息流短剧（签名拍）；悬疑推理、恐怖/怪谈高频。
- 不适用反例：非集首位置的悬念镜（用 suspense_reveal）；集首但无因果缺口、只是漂亮画面的建立镜（用 establishing）。

### transition 过渡/转场

- id：`transition`
- 中文名：过渡/转场
- 定义：连接两个叙事单元、只承担空间/时间/状态搬迁的镜头。
- 叙事功能：告诉观众「我们到了下一段因果」，自身不产生新冲突；快切建立动势，让观众感到进程在走。
- 基准时长区间：1.5–3.0 秒
- 强度缩放规则：1→3.0s / 3→2.2s / 5→1.5s（强度越高越短：搬迁越紧急越一笔带过）。
- 典型风格：平台信息流短剧、武侠动作、黑色电影（街景/雨夜搬迁）。
- 不适用反例：搬迁途中发生信息揭示或状态反转的镜（按揭示类贴）；生活流中刻意保留的完整行进过程（用 contemplation 或走风格校准）。

### exposition 说明/信息铺陈

- id：`exposition`
- 中文名：说明/信息铺陈
- 定义：交代人物关系、处境、规则等背景信息的镜头。
- 叙事功能：把观众理解后续情节所必需的前提放进其工作记忆；给足阅读时间，信息被读完即切。
- 基准时长区间：2.5–4.0 秒
- 强度缩放规则：1→2.5s / 3→3.2s / 5→4.0s（强度越高越长：信息密度越大越要留解码时间）。
- 典型风格：悬疑推理、黑色电影、平台信息流短剧（校准切碎后高频）。
- 不适用反例：信息以动作或对抗形式给出的镜（用 negotiation 或 action 类）；纯氛围无信息量的镜（用 silent_beat 或 establishing）。

### dialogue 对白

- id：`dialogue`
- 中文名：对白
- 定义：以人物台词交流为主体的镜头（含叙述旁白的画面镜）。
- 叙事功能：通过言语交换改变人物间的信息差、权力差或情感差；台词完整性优先于节奏档位。
- 基准时长区间：3.0–5.0 秒
- 强度缩放规则：1→5.0s / 3→4.0s / 5→3.0s（强度越高越短：交锋越激烈句读越紧、切点越抢；有台词时实际时长一律按对白时长预算公式计算，锚点仅供无台词/短台词参照）。示例：17 字台词 ≈ 17÷4 + 0.5 起音 + 0.5 反应 + 0.3 余量 = 5.55s，按 0.5s 网格收为 5.5s（数值仅演示格式）。
- 典型风格：黑色电影、爱情文艺、纪录片式；一切剧情类的承重拍。
- 不适用反例：言词交锋已构成攻防回合、看点在「谁压住谁」而非信息本身的镜（用 negotiation）；只有听没有说的镜（用 reaction_listen）。

### suspense_reveal 悬念/揭示

- id：`suspense_reveal`
- 中文名：悬念/揭示
- 定义：让一个悬而未决的问题逐步显形或在末端一次性揭示的镜头。
- 叙事功能：管理「知道一半」的状态——观众知道威胁/真相存在但看不全；长镜蓄压，揭示瞬间切走，把闭合感留给下一镜或下一段。
- 基准时长区间：4.0–8.0 秒
- 强度缩放规则：1→4.0s / 3→6.0s / 5→8.0s（强度越高越长：揭示越重，显形过程越要一寸一寸给；超过 5.0s 必须写明镜内信息注入方式）。
- 典型风格：恐怖/怪谈、悬疑推理、动画番剧演出。
- 不适用反例：一次性的信息反转、无蓄压过程的真相重述（用 twist_reveal）；揭示后观众消化反应（用 reaction_closeup 或 emotional_aftermath）。

### action_chase 动作/追逐

- id：`action_chase`
- 中文名：动作/追逐
- 定义：人物在空间中高速位移、看点在动势本身的镜头。
- 叙事功能：用物理位移推进目标—障碍冲突；短镜堆叠制造速度感，每镜只取位移的一个相位。
- 基准时长区间：1.5–3.0 秒
- 强度缩放规则：1→3.0s / 3→2.2s / 5→1.5s（强度越高越短）。
- 典型风格：武侠动作、平台信息流短剧、恐怖/怪谈（逃离段）。
- 不适用反例：站着打的招式交锋（用 action_exchange）；追逐进入末段加速、镜头比基准更碎的升级段（用 chase_escalation）。

### scare_climax 惊吓/冲突高点

- id：`scare_climax`
- 中文名：惊吓/冲突高点
- 定义：威胁刺点（stinger）或冲突爆发的瞬时镜头——突然闯入、声画齐爆的那一下。
- 叙事功能：把蓄压期累积的预期一次性兑现为生理级惊吓或情绪爆破；它必须短，因为惊吓反射由「突然性」而非「时长」触发。高节拍精度镜，切点容忍窗收紧。
- 基准时长区间：1.5–5.0 秒
- 强度缩放规则：1→5.0s / 3→2.5s / 5→1.5s（强度越高越短：最重的惊吓给最猝然的切口；5.0s 档保留给高潮处允许的一个稍长爆发镜）。
- 典型风格：恐怖/怪谈（签名拍）；武侠动作（杀招落点）、悬疑推理（罪案重现瞬间）。
- 不适用反例：刺点之前的蓄压镜（用 dread_build）；惊吓过后的喘息与重定性（用 emotional_aftermath 或 red_herring 的回落半段）。

### emotional_aftermath 情绪余韵

- id：`emotional_aftermath`
- 中文名：情绪余韵
- 定义：高强度事件之后的消化镜——人物或观众把刚发生的事「接住」。
- 叙事功能：完成威胁场景四阶段的「回落基线」环节，把生理唤醒转化为情绪意义；同时是留扣式收尾、章末余震的承载拍。
- 基准时长区间：3.0–8.0 秒
- 强度缩放规则：1→3.0s / 3→5.5s / 5→8.0s（强度越高越长：事件越重，消化越慢；情绪沉浸段用放宽档）。
- 典型风格：爱情文艺、生活流长镜、恐怖/怪谈（惊吓后回落）、一切高潮之后。
- 不适用反例：事件进行中的人物反应（用 reaction_closeup）；无前置强事件的平淡抒情镜（用 silent_beat 或 contemplation）。

### establishing 建立/空间定向

- id：`establishing`
- 中文名：建立/空间定向
- 定义：在动作开始前交代地点、格局、人物相对位置的镜头。
- 叙事功能：给观众一张「空间地图」，让后续所有轴线关系、出入画、追逐方向可被理解；连续性剪辑传统中它必须留足阅读时间，否则后续快切全部失去方向感。
- 基准时长区间：2.5–5.0 秒
- 强度缩放规则：1→2.5s / 3→3.5s / 5→5.0s（强度越高越长：空间越复杂、后续动作越依赖方位，定向越要给足）。
- 典型风格：纪录片式、黑色电影、生活流长镜；武侠动作开打前的场子扫描。
- 不适用反例：集首承担钩子的空间镜（用 opening_hook）；不带方位功能、只给氛围的空镜（用 silent_beat 或 contemplation）。

### reaction_listen 聆听/反应

- id：`reaction_listen`
- 中文名：聆听/反应
- 定义：对白或信息给出时，切到听者/旁观者的反应镜头。
- 叙事功能：确认信息被世界「接住」——观众借听者的脸校准自己该作何感受；同时充当对白场景的节奏换挡与视线切点。对白场景的剪辑规律是说者镜长、听者镜短，本类即那个「短」。
- 基准时长区间：1.5–3.5 秒
- 强度缩放规则：1→1.5s / 3→2.5s / 5→3.5s（强度越高越长：听到的内容越颠覆，反应越要停留到观众读出层次）。
- 典型风格：喜剧（反应即笑点）、纪录片式（采访）、一切对白承重风格。
- 不适用反例：反应本身成为信息主体、需要观众细读微表情的关键镜（用 reaction_closeup）；听话人同时也是下一个说话者的正反打主镜（用 dialogue）。

### reaction_closeup 反应特写

- id：`reaction_closeup`
- 中文名：反应特写
- 定义：关键信息落地后推近到面部的特写镜头，让观众逐层读出情绪变化。
- 叙事功能：把「认知转变」本身变成看点——观众不是被告知人物懂了，而是亲眼看见懂的过程；揭示类拍档，负责揭示之后的内心地震。
- 基准时长区间：2.0–5.0 秒
- 强度缩放规则：1→2.0s / 3→3.0s / 5→5.0s（强度越高越长：转变越大，读出层次所需时间越长）。
- 典型风格：悬疑推理（识破瞬间）、爱情文艺、动画番剧演出（演出特写跳切）。
- 不适用反例：常规的听者反应切出（用 reaction_listen）；无认知转变、只是情绪延续的面部停留（用 emotional_aftermath）。

### dread_build 蓄压

- id：`dread_build`
- 中文名：蓄压
- 定义：威胁逼近但未现身的长镜——缓慢推近、视线探查、日常细节异化。
- 叙事功能：威胁场景四阶段中的「预期蓄压」段。惊吓研究的可迁移机制：观众对惊吓的预期强度直接放大随后的惊吓反射强度与恐惧自评，蓄压段的长度与质量决定刺点能兑现多少；没有蓄压的惊吓只是廉价的 unprompted stinger。
- 基准时长区间：4.0–8.0 秒
- 强度缩放规则：1→4.0s / 3→6.0s / 5→8.0s（强度越高越长：预期积累是时间函数；较长镜头要有与本场表达相称的可观察变化或有意停留。摄影机变化、主体变化、环境变化、信息显露和声音均可独立或共同承担镜内进展；不规定镜内只能有一个摄影动作，也不因时长自动要求拆镜）。
- 典型风格：恐怖/怪谈（签名拍）、悬疑推理、动画番剧演出。
- 不适用反例：没有威胁预期的普通悬念（用 suspense_reveal）；蓄压已经兑现后的爆发镜（用 scare_climax）。

### red_herring 误导/虚惊

- id：`red_herring`
- 中文名：误导/虚惊
- 定义：建立一套错误预期并在镜内或紧邻处解除它的镜头——影子原来是人、异响原来是猫。
- 叙事功能：威胁场景四阶段的合法变体「abandoned stinger」：走完基线与预期蓄压，然后省略刺点直接回落，让观众先惊后松；或在推理线上喂养错误解释，为真揭示蓄能。机制要点：虚惊必须走完完整的预期弧，否则观众来不及上钩。
- 基准时长区间：2.5–5.0 秒
- 强度缩放规则：1→2.5s / 3→3.5s / 5→5.0s（强度越高越长：误导越重要，假弧越要做真）。
- 典型风格：恐怖/怪谈、悬疑推理、喜剧（预期违背即笑点的近亲）。
- 不适用反例：镜内没有解除、把误导留到后文才揭穿的镜（前半用 suspense_reveal，揭穿时用 twist_reveal）；纯气氛惊吓练习、不服务任何后续揭示（删，或降级为 transition）。

### twist_reveal 反转揭示

- id：`twist_reveal`
- 中文名：反转揭示
- 定义：一条信息落地，使已发生的一切被重新定性的镜头。
- 叙事功能：执行「认知重加工」——观众需要在镜内完成「啊，原来之前是那样」的倒带；它不靠蓄压而靠落差，落地后要停留到重加工完成。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：颠覆越彻底，倒带越久）。
- 典型风格：悬疑推理（签名拍）、黑色电影、平台信息流短剧（集尾反转钩）。
- 不适用反例：逐步显形、观众早有预期的揭示（用 suspense_reveal）；反转之后人物的反应特写（用 reaction_closeup）。

### comic_beat 喜剧节拍

- id：`comic_beat`
- 中文名：喜剧节拍
- 定义：构成一个笑点的最小镜头单元——铺垫、停顿或包袱落地三者之一。
- 叙事功能：执行 setup / pause / punch 的计时结构：铺垫建立预期，停顿让预期绷紧，包袱以预期违背落地；三件套中停顿拍可长，包袱拍必须短而准。可迁移机制：笑点强度与包袱镜头的停留时间成反比，抢半拍比拖半拍安全。
- 基准时长区间：1.5–4.0 秒
- 强度缩放规则：1→4.0s / 3→2.5s / 5→1.5s（强度越高越短：越大的笑点切口越脆）。
- 典型风格：喜剧（签名拍）、动画番剧演出（吐槽役快切）、平台信息流短剧（段子结构）。
- 不适用反例：靠台词本身逗乐、画面只是承载对白的镜（用 dialogue）；笑点之后观众的笑声缓冲/人物无奈（用 reaction_listen 或 emotional_aftermath 短档）。

### standoff 对峙僵持

- id：`standoff`
- 中文名：对峙僵持
- 定义：两方力量顶死、谁都不先动的静止张力镜头。
- 叙事功能：把冲突悬置为势能——看点是「谁先眨眼」；静止本身制造压力，镜内微变化（手、眼、呼吸）是唯一的动。武侠起手式、黑色电影谈判桌、恐怖对峙共用此结构。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：僵局越死，静止越要撑到观众屏息）。
- 典型风格：武侠动作、黑色电影、恐怖/怪谈。
- 不适用反例：对峙中已经开始言语交锋（用 negotiation）；僵局被打破后的第一动（用 action_exchange 或 scare_climax）。

### negotiation 谈判攻防

- id：`negotiation`
- 中文名：谈判攻防
- 定义：以言语为武器的回合制交锋镜头——报价、施压、让步、反将。
- 叙事功能：每个镜头是一个「回合」，改变双方的筹码分布或信息归属；看点在权力天平指针的来回，而非信息传递本身。与 dialogue 的区别：dialogue 交换信息，negotiation 交换地位。
- 基准时长区间：2.0–4.0 秒
- 强度缩放规则：1→4.0s / 3→3.0s / 5→2.0s（强度越高越短：交锋越白热，回合切换越快，正反打越抢）。
- 典型风格：黑色电影、悬疑推理（审讯）、平台信息流短剧（身份对撕、打脸前置）。
- 不适用反例：一方单向倾诉无回合结构（用 confession 或 dialogue）；交锋升级为肢体冲突（用 action_exchange）。

### time_compression 时间压缩蒙太奇

- id：`time_compression`
- 中文名：时间压缩蒙太奇
- 定义：把一段长时间过程（筹备、赶路、训练、搜查）压成一组短促并置的镜头单元。
- 叙事功能：蒙太奇学派的核心机制——用单元并置让观众自行合成「过程感」；每个单元只取过程的一个相位碎片，单镜不可读、并置才成立。
- 基准时长区间：1.0–2.5 秒
- 强度缩放规则：1→2.5s / 3→1.5s / 5→1.0s（强度越高越短：压缩比越大，单元越碎）。
- 典型风格：平台信息流短剧、武侠动作（赶路/备战）、悬疑推理（搜查段落）。
- 不适用反例：单个完整动作单元（拆断完整动作凑蒙太奇是禁项）；过程中发生了必须让观众看清的关键事件（该事件独立成镜，按其实际功能贴类）。

### silent_beat 静默拍

- id：`silent_beat`
- 中文名：静默拍
- 定义：无台词、无强动作，让人物或空间在静默中存在片刻的镜头。
- 叙事功能：节奏的「零」——没有静默作底，快慢两极都失去标尺；让上一拍的信息沉淀、让下一拍的起速有可感的对比。小津「枕镜」方向的可迁移机制：叙事事件之间的空转不是浪费，是给观众情绪落座的时间。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：越重的静默越要敢于停）。
- 典型风格：生活流长镜、爱情文艺、恐怖/怪谈（惊吓前的死寂）。
- 不适用反例：静默中有未闭合威胁预期在爬升（用 dread_build）；只是没写清楚功能的过渡空镜（先回答叙事功能，再决定贴不贴）。

### ritual 仪式拍

- id：`ritual`
- 中文名：仪式拍
- 定义：以程式化、重复性、装饰性调度执行的镜头——礼拜、卜筮、摆阵、变身、家宴座次。
- 叙事功能：把动作升格为「仪式」，看点在形式本身的庄严或诡异；重复与对称为后续「仪式被破坏」储存冲击势能。装饰动画方向（如浮世绘拼贴式演出）的可迁移机制：仪式感来自节拍的等距重复与画面符号密度，而非信息增量。
- 基准时长区间：2.5–6.0 秒
- 强度缩放规则：1→2.5s / 3→4.0s / 5→6.0s（强度越高越长：程式越完整，越要不吝时间把每个步骤做足）。
- 典型风格：动画番剧演出（签名拍）、恐怖/怪谈（民俗仪式）、武侠动作（结印/起手式）。
- 不适用反例：有实用目的、不看形式看结果的操作过程（用 time_compression）；仪式被意外打断的那一刻（按打断性质贴 scare_climax 或 twist_reveal）。

### plant_setup 伏笔铺设

- id：`plant_setup`
- 中文名：伏笔铺设
- 定义：让一个日后回收的细节（道具、台词、习惯、画面元素）被观众「看见但没多想」的镜头。
- 叙事功能：在观众记忆里存一笔未标价的账；机制上的两难是——太短观众没存入，太长等于举牌预告，所以它的区间刻意压在中短档，靠构图与声音轻度强调而非时长强调。
- 基准时长区间：1.5–3.0 秒
- 强度缩放规则：1→1.5s / 3→2.0s / 5→3.0s（强度越高越长：伏笔越关键，越要确保登记成功，但 3.0s 封顶防止预告化）。
- 典型风格：悬疑推理（签名拍）、黑色电影、恐怖/怪谈。
- 不适用反例：铺设对象本身就是当前场面焦点（用 exposition 或 suspense_reveal）；伏笔回收镜（用 payoff 或 twist_reveal）。

### payoff 伏笔兑现/高光兑现

- id：`payoff`
- 中文名：伏笔兑现/高光兑现
- 定义：回收早前伏笔或兑现全片承诺的高光镜头——观众认出「原来是它」并完成意义闭环。
- 叙事功能：把存款连本带息取出：观众需要认出旧元素、接通新语境、体验兑现快感，三段认知缺一不可，因此它有全局地板约束（见 §5 `role_floors.payoff_s`），与「高光兑现镜 ≥5s」的节奏极值锚定规则同源。
- 基准时长区间：5.0–8.0 秒
- 强度缩放规则：1→5.0s / 3→6.5s / 5→8.0s（强度越高越长：兑现越重，闭环仪式越要完整；超过 5.0s 必须写明镜内信息注入）。
- 典型风格：悬疑推理（解谜兑现）、武侠动作（绝技亮相）、一切有伏笔结构的剧情类。
- 不适用反例：兑现瞬间之后的庆祝/代价展示（用 emotional_aftermath 或 defeat_beat）；无伏笔存根的新信息揭示（用 twist_reveal——无账可取不叫兑现）。

### defeat_beat 挫败拍

- id：`defeat_beat`
- 中文名：挫败拍
- 定义：人物遭遇不可逆失败、计划破产或信念崩塌后独自承受后果的镜头。
- 叙事功能：节拍表上「一无所有」位的单镜形态：让观众陪着人物触底，为反弹蓄能；机制是「静止的承重」——人物不动，世界继续动（环境声、他人远去），落差即是痛感。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：挫败越彻底，触底越要坐实）。
- 典型风格：黑色电影、爱情文艺、生活流长镜。
- 不适用反例：失败正在发生的动作镜（按动作类贴）；挫败之后的颓废蒙太奇（用 time_compression 或 emotional_aftermath）。

### chase_escalation 追逐升级

- id：`chase_escalation`
- 中文名：追逐升级
- 定义：追逐/动作进入末段加速期的镜头，比基准动作拍更碎更急。
- 叙事功能：执行动作段落的加速度曲线——剪辑节奏本身模拟失控与逼近；可迁移机制：升级感来自镜头时长的递减序列与空间余量（出画空间、距离）的可见收缩，而不是单镜的绝对短。
- 基准时长区间：1.0–2.5 秒
- 强度缩放规则：1→2.5s / 3→1.5s / 5→1.0s（强度越高越短）。
- 典型风格：武侠动作、平台信息流短剧、恐怖/怪谈（被追段）。
- 不适用反例：追逐的常速巡航段（用 action_chase）；升级后撞上高潮的那一下（用 scare_climax）。

### tension_beat 暧昧张力

- id：`tension_beat`
- 中文名：暧昧张力
- 定义：两人之间未说出口的情愫、欲望或敌意以凝视、距离、触碰悬置形式存在的镜头。
- 叙事功能：把关系张力保持为「未决」——看点是距离的最小化与始终不闭合；机制与 standoff 同构（势能悬置），但标的是情感而非武力，镜内微变化是视线的接与躲。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：张力越满，悬置越要撑到观众替人物着急）。
- 典型风格：爱情文艺（签名拍）、黑色电影（蛇蝎美人对局）、生活流长镜。
- 不适用反例：张力已经说破进入对白交锋（用 dialogue 或 negotiation）；张力闭合的拥抱/亲吻落点镜（用 emotional_aftermath 或 payoff）。

### exposition_managed 受控信息倾倒

- id：`exposition_managed`
- 中文名：受控信息倾倒
- 定义：不得不一次性给出大段信息（推理链、前史、规则体系）时，把信息切碎并挂在动作、场景变换或对抗上的镜头。
- 叙事功能：执行「夹心药丸」机制——每镜只递送一个信息块，块间用视线、位移或反问制造推进感，让观众在追动作的过程中顺便吞信息；与 exposition 的区别在于它管理的是「信息过载风险」。
- 基准时长区间：2.5–4.5 秒
- 强度缩放规则：1→2.5s / 3→3.5s / 5→4.5s（强度越高越长：单块信息越复杂，解码时间越要给足，但块必须继续切小而不是把镜拉长）。
- 典型风格：悬疑推理（解谜段）、黑色电影（案情复述）、平台信息流短剧（世界观速通）。
- 不适用反例：单条轻信息（用 exposition）；信息倾倒实为人物倾倒情绪（用 confession）。

### action_exchange 攻防回合

- id：`action_exchange`
- 中文名：攻防回合
- 定义：招式交锋的最小单元镜——一攻一防、一进一退，每镜一个技术相位。
- 叙事功能：香港动作剪辑的可迁移机制：回合制清晰性优先于碎切刺激——观众必须看清「谁出了什么、谁接住了、谁吃了亏」，每镜是回合记录而非速度粉末；重击落点后可跟一个短促的定势顿挫（pose accent）再续攻，顿挫本身是节奏标点而非独立拍。
- 基准时长区间：1.0–2.5 秒
- 强度缩放规则：1→2.5s / 3→1.8s / 5→1.0s（强度越高越短：回合越到胜负手越连环加速）。
- 典型风格：武侠动作（签名拍）、平台信息流短剧（打斗名场面）。
- 不适用反例：无对手的位移动作（用 action_chase）；回合结构崩坏、刻意模拟主观混乱的段落（用 panic_fragment）。

### contemplation 凝视/观察

- id：`contemplation`
- 中文名：凝视/观察
- 定义：摄影机以旁观者距离长时间凝视一个日常行为或空间的镜头，不催迫事件发生。
- 叙事功能：生活流美学的核心机制——时间本身成为内容：观众从「等事件发生」切换到「观察存在的质地」；计量电影学数据显示小津晚期作品 ASL 约 7–13 秒且多数镜头落在 0–22 秒带，其「慢」主要来自固定机位与留白而非极端镜长——本参照系取其方向、按硬边界封顶。
- 基准时长区间：5.0–8.0 秒
- 强度缩放规则：1→5.0s / 3→6.5s / 5→8.0s（强度越高越长：凝视越彻底越接近凝视本身的目的；需要超过 8.0s 时走一镜到底/长镜豁免路径，不改区间）。
- 典型风格：生活流长镜（签名拍）、纪录片式、爱情文艺。
- 不适用反例：凝视中有威胁预期在积累（用 dread_build——观察与监视是两回事）；只是还没想好怎么切的长镜（先回答功能）。

### panic_fragment 慌乱碎切

- id：`panic_fragment`
- 中文名：慌乱碎切
- 定义：模拟人物主观混乱状态的极短破碎镜头——手持、失焦、不完整构图、动作相位断裂。
- 叙事功能：放弃回合清晰性，让观众「体验」而非「看懂」混乱；可迁移机制：主观化碎切的信息量刻意低于观众解码速度，认知缺口本身即恐慌。整段使用时长占比须克制，连续碎切超过一个段落即转为噪声。
- 基准时长区间：0.8–2.0 秒
- 强度缩放规则：1→2.0s / 3→1.4s / 5→0.8s（强度越高越短）。
- 典型风格：恐怖/怪谈（受害者视角）、平台信息流短剧（翻车瞬间）、纪录片式（突发事件跟拍）。
- 不适用反例：观众需要看清因果的关键动作（用 action_exchange——慌乱不能吃掉叙事责任）；事后回放的同一段动作（按回放功能重新贴类）。

### confession 独白倾诉

- id：`confession`
- 中文名：独白倾诉
- 定义：人物卸下防御的长段独白，或旁白式自我陈述的承载镜头。
- 叙事功能：把人物的内在账簿一次摊开——黑色电影旁白、忏悔室、深夜自白共用此结构；看点是「说的人渐渐撑不住」的过程，镜头要长在人物脸上而不是四处补画面。
- 基准时长区间：4.0–8.0 秒
- 强度缩放规则：1→4.0s / 3→6.0s / 5→8.0s（强度越高越长：防御剥落得越深，越要不打岔地陪到底；有台词时按对白时长预算公式，锚点为无台词参照）。
- 典型风格：黑色电影（签名拍）、爱情文艺、纪录片式（采访自述）。
- 不适用反例：有来有回的言语交锋（用 negotiation 或 dialogue）；独白内容实为信息倾倒（用 exposition_managed）。

## §3 风格节奏档案

每个风格档案给出：签名 beat 组合、节奏气质、校准倾向（见本节末尾机器表）、可迁移机制。风格只校准区间，不创造新拍类；本档案不列片单、不抄任何具体作品的镜头安排，只提炼机制。

### horror_dread 恐怖/怪谈

- 签名 beat 组合：dread_build → scare_climax → emotional_aftermath 的威胁场景四阶段循环（基线 → 预期蓄压 → 刺点到达 → 回落基线），穿插 red_herring（abandoned stinger 变体）与 suspense_reveal。
- 节奏气质：蓄压极长、刺点极短、回落放慢；全片是「慢—极快—慢」的脉冲序列而非均匀紧张。
- 可迁移机制：惊吓研究的四阶段模型——预期阶段的视听线索会预先抬高惊吓反射幅度，因此蓄压段的长度与质量直接兑换刺点的强度；虚惊（省略刺点直接回落）是合法且必要的节奏调剂，但虚惊也必须走完完整预期弧；刺点镜头必须猝然——惊吓反射由突然性触发，不由时长触发；刺点后立即回落并重新定性（原来是公交车），回落速度决定下一轮蓄压何时能再启动。
- 校准示例：一个循环可以是蓄压 7.4s → 刺点 1.2s → 回落 4.6s（数值仅演示格式）。

### comedy 喜剧

- 签名 beat 组合：comic_beat（setup / pause / punch 三件套）+ reaction_listen（反应即笑点放大器）+ dialogue（收紧档）。
- 节奏气质：切口快、停顿准；全片平均偏快，但停顿拍敢于悬空。
- 可迁移机制：setup–pause–punch 的计时结构——铺垫建立预期，停顿让预期绷紧，包袱以违背落地；包袱镜头停留时间与笑点强度成反比，抢半拍比拖半拍安全；反应切出是对白场景的节拍器，说者镜长听者镜短；三件套（rule of three）中第三次重复必须变奏，否则预期兑现成无趣。

### wuxia_action 武侠动作

- 签名 beat 组合：standoff（起手对峙）→ action_exchange（回合制攻防，含重击后的定势顿挫）→ chase_escalation（末段加速）→ 高点一记 scare_climax 档爆发。
- 节奏气质：回合清晰、张弛分明；静（对峙）极静，动（连招）极碎。
- 可迁移机制：回合制清晰性优先于碎切刺激——观众必须看清攻防相位与代价归属，每镜一个技术相位；节奏标点靠定势顿挫（重击落点后的短促 pose hold），不靠匀速；加速度曲线靠镜头时长递减序列与空间余量收缩共同表达；开打前的对峙不是慢，是给后续快切储存对照势能。

### noir 黑色电影

- 签名 beat 组合：dialogue（放缓档）+ confession（旁白/自白）+ standoff（谈判桌对峙）+ establishing（阴影空间定向）。
- 节奏气质：刻意放缓、密度低而压强高；长镜留给语言与沉默，快切只留给暴力。
- 可迁移机制：语言的重量由停顿与镜长共同承载——把对白镜放宽，让威胁在句读之间生效；旁白式自白把认知视角锁死在讲述者身上，画面节奏服从叙述节奏；空间定向镜因阴影遮蔽信息而需要更长阅读时间。

### slow_cinema 生活流长镜

- 签名 beat 组合：contemplation（凝视）+ silent_beat（枕镜式留白）+ establishing（放宽档）+ transition（保留完整行进）。
- 节奏气质：留白多、起速慢；事件稀疏但每镜质地饱满。
- 可迁移机制：时间本身成为内容——观众从「等事件」切换到「观察存在质地」，凝视镜是这种切换的开关；枕镜机制：叙事事件之间插入空转镜，让上一事件沉淀、下一事件起速有对比；计量数据显示该方向「慢」的主要来源是固定机位与留白结构而非无限镜长，迁移到短剧参照系时放宽区间但仍受单镜硬边界约束，更长需求走长镜豁免。

### anime_stylized 动画番剧演出

- 签名 beat 组合：ritual（仪式/程式演出）+ comic_beat（吐槽快切）+ reaction_closeup（演出特写）+ suspense_reveal。
- 节奏气质：形式驱动、拍点等距与猝停交替；装饰段落仪式感极强，日常段落吐槽切口极快。
- 可迁移机制：仪式感来自节拍等距重复与画面符号密度而非信息增量——重复为「仪式被破坏」蓄能；演出特写可跳切（同一主体景别突变而不走连续运动），靠图形冲击而非运动连贯；吐槽役快切证明极短镜也可以承载语言信息，前提是语音与字幕设计同步收紧。

### platform_feed 平台信息流短剧

- 签名 beat 组合：opening_hook（黄金窗口收紧档）+ time_compression + negotiation（对撕/打脸）+ twist_reveal（集尾反转钩）。
- 节奏气质：切口快、钩子密度高、蓄压让位；一切长拍都必须证明自己留得住人。
- 可迁移机制：黄金三秒——平台数据表明用户平均在开头数秒内决定滑走或看完，因此集首窗口的信息事件密度直接挂钩完播；钩子不是「吵」，是未闭合的因果缺口；高密度段靠每镜一个信息事件维持，单镜碎不等于节奏好，事件密度才是分子；集尾反转钩把完播转化为追更。
- 校准示例：开场前 2.6s 内排进 4 个信息事件（数值仅演示格式）。

### mystery_detective 悬疑推理

- 签名 beat 组合：plant_setup → suspense_reveal → exposition_managed（推理链）→ twist_reveal → payoff 的伏笔全生命周期。
- 节奏气质：中速偏稳，揭示点刻意拉长；信息拍远多于动作拍。
- 可迁移机制：伏笔经济学——铺设拍要「被看见但没多想」（中短档 + 轻度强调），兑现拍要给足再加工时间（长档 + 镜内注入）；悬念与惊讶的分工（炸弹理论方向）：让观众比人物早知道则时间换成悬念，让观众与人物同时知道则换成惊讶，两种机制对应不同拍类，不可混贴；推理链信息用「夹心药丸」切块，挂在追问与位移上递送。

### romance_art 爱情文艺

- 签名 beat 组合：tension_beat（未闭合凝视）+ silent_beat + dialogue（留白档）+ emotional_aftermath。
- 节奏气质：悬置长、落点软；张力的价值在未决，闭合要克制。
- 可迁移机制：张力与对峙同构——势能来自「距离最小化但始终不闭合」，镜内微变化（视线接与躲、呼吸）是唯一允许的动；留白是对白的第二声道，台词镜收紧、静默镜放宽，让没说出口的部分承载信息；余韵拍是情感兑现的主币，比直白告白镜头权重更高。

### documentary 纪录片式

- 签名 beat 组合：establishing（观察档）+ contemplation + reaction_listen（采访听反应）+ dialogue（陈述完整保留）。
- 节奏气质：尊重真实时间、少干预；切点跟随事件自身相位而非制造节拍。
- 可迁移机制：观察者优先——镜头时长跟随被摄事件的完整相位，不为节拍拆断真实动作；采访场景的听反应是信息真实性的一部分（提问者的在场证明陈述不是配音）；不可干预事件的慌乱时刻允许 panic_fragment 档碎切，真实性感知优先于可读性。

### 参数说明（人读部分）

**speech.\*（语音时长预算）**：对白镜时长的推导公式为「台词字数 ÷ chars_per_s + onset_s + reaction_s + 余量」。`chars_per_s_normal: 4` 与 `chars_per_s_rapid: 5` 是常态/急速两档中文配音语速；`onset_s: 0.5` 是台词起音前的入场留白，`reaction_s: 0.5` 是台词落点后的反应留白，`min_overhead_s: 0.3` 是任何含语音镜的最小附加余量。调参影响：语速值上调会系统性压缩全部对白镜时长、推高全片剪辑速率；onset/reaction 是对白镜的情绪地板，压到 0 会让对白失去呼吸感，台词完整性与节奏档位冲突时以台词为准。

**rounding_grid_s（取整网格）**：所有推导出的期望时长向 0.5 秒网格收拢。调大网格会让节奏更「粗」但切点漂移容忍度更高；调小则计划更精细但生成端漂移更容易出格。

**role_floors.\*（角色地板）**：高光兑现镜（payoff）与本集最终镜（final）的时长地板均为 5.0 秒，对应节奏极值锚定中「最长拍必须真实存在」的规则。确需短促切断（留扣式收尾）时不改地板值，走例外登记。

**shot_bounds.\*（单镜计划范围）**：单镜计划范围通常为 0.8–8.0 秒；具体一镜到底及长镜豁免按 `storyboard.md` 判断。`info_injection_threshold_s: 5.0` 是复核提示：超过该时长且未标记 `info_injection` 时，引擎提醒创作者确认镜内发展或停留意图；提醒不代表设计失败，也不自动要求切开。镜长由节拍、对白、动作、观看和生成能力共同决定。

**kf.\*（关键帧预算）**：每集关键帧 `min: 3`、常规上限 `base_max: 4`；单集超过 `long_episode_threshold_s: 300` 秒后，每超出 `step_s: 180` 秒上限加 1，`cap: 6` 封顶；每个 SEG 最多 `per_seg_max: 2` 张。调参影响：cap 决定一集视觉锚点的记忆预算，per_seg_max 防止单个段落吃光全集关键帧。示例：510 秒长集触发长集档位、关键帧上限由 4 升至 5（数值仅演示格式）。

**high_density.\*（高密度段形态）**：`min_shots: 8` 仅作高密度短段的诊断参考，不是质量门或增镜配额；镜数由可见信息事件、动作职责、表演反应与自然切点决定，不按是否恰为 15 秒触发。`golden_window_s` 与 `first_shot_max_s` 只在项目规划明确采用信息流黄金三秒目标时作为参考，不由 H3 技术上限自动触发。不得为满足这些参考值拆断动作或改写镜长。示例：14 秒高密度段排 9 镜、段 ASL 约 1.6s 属正常形态（数值仅演示格式）。

**asl_targets.\*（段级 ASL 目标）**：dialogue_emotional 与 suspense_build 段的目标平均镜长 2.5–4.0 秒，micro_film 段 3.0–6.0 秒。这是段级健康度判定标尺，与单镜 beat 区间是两层指标：单镜可以出格（走例外），段均值应落带内。

**health.\*（节奏健康度阈值族）**：分布健康的判定常量——`segment_min_range_s: 1.0` 段内时长极差下限；`flatline_window_s: 2.0` 与 `flatline_max_share: 0.7` 判定分布扁平（任一 2 秒窗内镜头占比超 70% 必须按强度重分配）；`fast_pole_max_s: 3.0` 要求含 §4 `fast_pole_capable=yes` 的快节奏节拍（惊吓/动作/切口类）时最短镜 ≤3 秒（快极存在）——是否触发只看 §4 显式标记，不由锚点数值推断；`slow_pole_min_s: 6.0` 与 `slow_pole_min_total_s: 300` 要求长片最慢镜 ≥6 秒（慢极存在）；`beat_monoculture_max_share: 0.6` 单一 beat_type 占比上限；`cap_uniformity_min_segments: 8` 与 `cap_uniformity_share: 0.85` 判定段落镜数均匀化（防节拍器结构）；`speech_voice_max_share_normal: 0.55` / `speech_voice_max_share_dense: 0.7` 为常态/高密度段的语音时长占比上限（防台词灌满挤压画面叙事）。

**shot_count_risk_threshold（镜数风险阈值）**：单段镜数达到 6 即触发生成端合并相邻镜/丢弱镜的风险标注，需在批次确认中点名；它不是镜数上限，是风险提示线。
