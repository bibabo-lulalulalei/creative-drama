# 节拍类型库（beat_type 分类学与节奏参数权威）
library_version: 2

本库是 doubao-creative-drama 节奏系统的唯一人类权威：§2/§4 定义叙事节拍分类、基准时长区间与强度锚点；§3 定义风格节奏档案及其时长校准；§5 固化节奏参数。生成器只解析文件头版本行、§3 末尾机器表、§4 机读映射表与 §5 节奏参数表；其余章节为给导演阅读的说明。散文与机器表不一致时，以机器表为准并修复散文。

---

## §1 使用规则

### beat_type 是什么

`beat_type` 是**叙事功能与节奏时长的标注**：它描述一个镜头在因果链中对观众产生的主要作用，并提供时长参考；它不是摄影或剪辑指令。它与段级 `density_profile` 正交：后者描述段落整体的节奏走势，前者标记单镜的主要叙事作用。同一段可混合多种类型，也可留空；分类不要求拆镜、补镜或改变场面调度。

### 选类流程

导演先根据故事、观众视点、空间关系、情绪变化和场面调度自由设计观看过程，再问「**这个镜头主要改变了观众的什么认知、感受或局势**」，最后才决定是否标注 beat_type 并核对时长。beat_type 只记录已经形成的设计，不得反过来生成或限制拍法。判断功能时可参考：

1. 这镜让观众**知道**了什么新东西（信息类：exposition / exposition_managed / plant_setup / twist_reveal / suspense_reveal / red_herring）？
2. 这镜让观众**感到**了什么（情绪类：dread_build / scare_climax / emotional_aftermath / silent_beat / tension_beat / defeat_beat / comic_beat）？
3. 这镜让局势**推进**了什么（行动类：action_chase / action_exchange / chase_escalation / negotiation / standoff / time_compression）？
4. 这镜主要承担什么结构作用（如 opening_hook / transition / establishing / reaction / contemplation / ritual / confession / payoff）？

一个镜头可以同时承载相互关联的信息、动作、反应和情绪变化。需要标注时，只选最能解释其主要因果作用的一类；无法概括或标注会误导时留空。不得为了贴合分类拆开本来连贯的观看过程。

### 三层生效区间优先级

同一 beat_type 的时长区间按以下优先级取生效值，上层覆盖下层：

1. **本集声明 overrides**：导演总控卡或分镜 JSON 中对本集特定 beat_type 的显式区间声明；
2. **风格档案**：§3 机器表中「风格 × 节拍」组合的校准区间；
3. **本库默认值**：§2/§4 的基准区间。

未命中前两层时落回本库默认。三层之外不允许第四套私设区间；确需破例（如留扣式收尾、一镜到底长镜）走 skill 既有的例外登记路径，不改区间。

### 参照系声明

本库全部基准时长区间以 **60–180 秒短剧单集** 为参照系：即一集总时长在一到三分钟的竖屏/横屏 AI 生成短剧，单镜受全局硬边界 0.8–8.0 秒约束（见 §5 `shot_bounds`）。长片语境的同类节拍普遍更长（如长片蓄压段常见数十秒），移植到本参照系时已按短剧注意力预算压缩；反之，把本库区间直接套用到十分钟以上内容会系统性偏短。

### 强度缩放

每类给出强度 1 / 3 / 5 三个锚点值，强度 2、4 及小数强度由相邻锚点**分段线性插值**得到。锚点的单调方向由数值本身表达：蓄压类（dread_build、suspense_reveal 等）强度越高越长，惊吓/切口类（scare_climax、comic_beat、action_exchange 等）强度越高越短。示例：`suspense_reveal` 锚点 4.0 / 6.0 / 8.0，强度 4 落在 6.0 与 8.0 的中点 7.0s（数值仅演示格式）。

### 禁项

1. **不得取区间中值作默认值**。中值只是锚点 3 碰巧落在几何中点时的巧合；赋值必须来自强度锚点插值，并经由相邻镜对比微调，使每镜能回答「为什么是这个时长」。
2. **不得为凑类型硬贴标签**。beat_type 是描述性的不是配额的；不存在「每段必须凑够 N 种类型」的要求。
3. **无合适类型时留空**。没有任何一类贴合本镜功能时，`beat_type` 留空，时长改由段级 intensity 序列与节奏极值锚定流程推导，事后在分镜说明里写一句推导依据。留空优于错贴。

## §2 beat_type 总表

共 30 类。前 8 类为 lint 现有合同（id 与默认区间冻结，不得改）；后 22 类为本库扩展。类型只描述叙事功能和节奏，不是拍法目录；景别、机位、运镜、构图、焦点、剪辑、镜头数及表演调度由导演根据当前场景独立设计。每类字段固定：id、中文名、定义、叙事功能、基准时长区间、强度缩放规则、不适用反例。所有区间为 60–180 秒短剧参照系下的单镜秒数，含全局计划时长范围 0.8–8.0 秒；超过 5.0 秒会提示检查镜内发展或有意停留，但不自动要求拆镜（见 §5 `shot_bounds.info_injection_threshold_s`）。

### opening_hook 开场钩子

- id：`opening_hook`
- 中文名：开场钩子
- 定义：集首用最短时间制造「必须看下去」的问题、冲突或奇观的镜头。
- 叙事功能：在平台滑走决策窗口内建立观看契约——抛出未闭合的因果缺口（反常画面、对峙中景、后果先行），不解释、只欠账。
- 基准时长区间：0.8–3.0 秒
- 强度缩放规则：1→3.0s / 3→1.8s / 5→0.8s（强度越高越短：钩子越尖锐，关键信息越早进入观众注意）。
- 不适用反例：非集首位置的悬念镜（用 suspense_reveal）；集首但无因果缺口、只是漂亮画面的建立镜（用 establishing）。

### transition 过渡/转场

- id：`transition`
- 中文名：过渡/转场
- 定义：连接两个叙事单元，主要作用是让观众理解空间、时间或状态已经发生迁移。
- 叙事功能：标记因果段落之间的过渡；是否呈现环境、人物、动作或其他信息，由具体场景决定。
- 基准时长区间：1.5–3.0 秒
- 强度缩放规则：1→3.0s / 3→2.2s / 5→1.5s（强度越高越短：搬迁越紧急越一笔带过）。
- 不适用反例：搬迁途中发生信息揭示或状态反转的镜（按揭示类贴）；生活流中刻意保留的完整行进过程（用 contemplation 或走风格校准）。

### exposition 说明/信息铺陈

- id：`exposition`
- 中文名：说明/信息铺陈
- 定义：交代人物关系、处境、规则等背景信息的镜头。
- 叙事功能：把观众理解后续情节所必需的前提放进其工作记忆；给足阅读时间，信息被读完即切。
- 基准时长区间：2.5–4.0 秒
- 强度缩放规则：1→2.5s / 3→3.2s / 5→4.0s（强度越高越长：信息密度越大越要留解码时间）。
- 不适用反例：信息以动作或对抗形式给出的镜（用 negotiation 或 action 类）；纯氛围无信息量的镜（用 silent_beat 或 establishing）。

### dialogue 对白

- id：`dialogue`
- 中文名：对白
- 定义：以人物台词交流为主体的镜头（含叙述旁白的画面镜）。
- 叙事功能：通过言语交换改变人物间的信息差、权力差或情感差；台词完整性优先于节奏档位。
- 基准时长区间：3.0–5.0 秒
- 强度缩放规则：1→5.0s / 3→4.0s / 5→3.0s（强度越高越短：交锋越激烈句读越紧、切点越抢；有台词时实际时长一律按对白时长预算公式计算，锚点仅供无台词/短台词参照）。示例：17 字台词 ≈ 17÷4 + 0.5 起音 + 0.5 反应 + 0.3 余量 = 5.55s，按 0.5s 网格收为 5.5s（数值仅演示格式）。
- 不适用反例：言词交锋已构成攻防回合、看点在「谁压住谁」而非信息本身的镜（用 negotiation）；只有听没有说的镜（用 reaction_listen）。

### suspense_reveal 悬念/揭示

- id：`suspense_reveal`
- 中文名：悬念/揭示
- 定义：让一个悬而未决的问题逐步显形或在末端一次性揭示的镜头。
- 叙事功能：管理观众对未决问题的认知，使信息逐步显现或在关键时刻改变观众理解；如何安排揭示与闭合由导演结合场景判断。
- 基准时长区间：4.0–8.0 秒
- 强度缩放规则：1→4.0s / 3→6.0s / 5→8.0s（强度越高越长：揭示越重，显形过程越要一寸一寸给；超过 5.0s 必须写明镜内信息注入方式）。
- 不适用反例：一次性的信息反转、无蓄压过程的真相重述（用 twist_reveal）；揭示后观众消化反应（用认知反应或 emotional_aftermath）。

### action_chase 动作/追逐

- id：`action_chase`
- 中文名：动作/追逐
- 定义：人物在空间中高速位移、看点在动势本身的镜头。
- 叙事功能：通过人物或物体的空间位移推进目标与障碍之间的冲突；镜头组织应让观众能够理解行动结果及其代价。
- 基准时长区间：1.5–3.0 秒
- 强度缩放规则：1→3.0s / 3→2.2s / 5→1.5s（强度越高越短）。
- 不适用反例：站着打的招式交锋（用 action_exchange）；追逐进入末段加速、镜头比基准更碎的升级段（用 chase_escalation）。

### scare_climax 惊吓/冲突高点

- id：`scare_climax`
- 中文名：惊吓/冲突高点
- 定义：威胁刺点（stinger）或冲突爆发的瞬时镜头——突然闯入、声画齐爆的那一下。
- 叙事功能：让威胁或冲突在关键节点突然兑现，造成惊吓、冲击或情绪爆发；强度取决于前置预期与结果落差，不预设镜头时长、剪辑方式或摄影反应。
- 基准时长区间：1.5–5.0 秒
- 强度缩放规则：1→5.0s / 3→2.5s / 5→1.5s（强度越高越短：最重的惊吓给最猝然的切口；5.0s 档保留给高潮处允许的一个稍长爆发镜）。
- 不适用反例：刺点之前的蓄压镜（用 dread_build）；惊吓过后的喘息与重定性（用 emotional_aftermath 或 red_herring 的回落半段）。

### emotional_aftermath 情绪余韵

- id：`emotional_aftermath`
- 中文名：情绪余韵
- 定义：高强度事件之后的消化镜——人物或观众把刚发生的事「接住」。
- 叙事功能：完成威胁场景四阶段的「回落基线」环节，把生理唤醒转化为情绪意义；同时是留扣式收尾、章末余震的承载拍。
- 基准时长区间：3.0–8.0 秒
- 强度缩放规则：1→3.0s / 3→5.5s / 5→8.0s（强度越高越长：事件越重，消化越慢；情绪沉浸段用放宽档）。
- 不适用反例：事件进行中的人物反应（用认知反应）；无前置强事件的平淡抒情镜（用 silent_beat 或 contemplation）。

### establishing 建立/空间定向

- id：`establishing`
- 中文名：建立/空间定向
- 定义：在动作开始前交代地点、格局、人物相对位置的镜头。
- 叙事功能：帮助观众理解场景空间及其与人物行动的关系；所需信息和呈现时机取决于后续叙事，不规定构图、景别或剪辑方法。
- 基准时长区间：2.5–5.0 秒
- 强度缩放规则：1→2.5s / 3→3.5s / 5→5.0s（强度越高越长：空间越复杂、后续动作越依赖方位，定向越要给足）。
- 不适用反例：集首承担钩子的空间镜（用 opening_hook）；不带方位功能、只给氛围的空镜（用 silent_beat 或 contemplation）。

### reaction_listen 聆听/反应

- id：`reaction_listen`
- 中文名：聆听/反应
- 定义：对白或信息引发听者、旁观者或其他相关对象的反应，且该反应对观众理解场面有作用。
- 叙事功能：呈现信息在关系、认知或情绪上的影响；是否单独呈现反应以及如何组织画面，由导演按场面需要决定。
- 基准时长区间：1.5–3.5 秒
- 强度缩放规则：1→1.5s / 3→2.5s / 5→3.5s（强度越高越长：听到的内容越颠覆，反应越要停留到观众读出层次）。
- 不适用反例：反应没有带来新的认知、情绪或关系信息时，不必单独标注反应类节拍。

### reaction_closeup 认知反应

- id：`reaction_closeup`（历史兼容 ID，不表示景别要求）
- 中文名：认知反应
- 定义：信息或事件使人物的理解、判断或情绪发生可被观众感知的变化。
- 叙事功能：把认知变化本身作为观众需要理解的结果；不要求人物面部特写、推近或单独切出。
- 基准时长区间：2.0–5.0 秒
- 强度缩放规则：1→2.0s / 3→3.0s / 5→5.0s（强度越高越长：变化越大，观众理解其过程所需时间越长）。
- 不适用反例：反应没有带来新的认知或情绪信息时，不必单独标注；情绪只是延续时可用 emotional_aftermath。

### dread_build 蓄压

- id：`dread_build`
- 中文名：蓄压
- 定义：威胁尚未兑现，但观众对风险或未知结果的预期逐步增强。
- 叙事功能：让观众对威胁、未知结果或即将到来的变化形成并累积预期。是否需要后续兑现、如何兑现以及是否形成完整的蓄压结构，由故事决定。
- 基准时长区间：4.0–8.0 秒
- 强度缩放规则：1→4.0s / 3→6.0s / 5→8.0s（强度越高越长：预期积累需要更多时间；较长镜头应有与本场表达相称的可观察变化或有意停留。变化可以来自信息、行动、环境、声音或观看关系，不指定其具体视听手段，也不因时长自动要求拆镜）。
- 不适用反例：没有威胁预期的普通悬念（用 suspense_reveal）；蓄压已经兑现后的爆发镜（用 scare_climax）。

### red_herring 误导/虚惊

- id：`red_herring`
- 中文名：误导/虚惊
- 定义：建立一套错误预期并在镜内或紧邻处解除它的镜头——影子原来是人、异响原来是猫。
- 叙事功能：威胁场景四阶段的合法变体「abandoned stinger」：走完基线与预期蓄压，然后省略刺点直接回落，让观众先惊后松；或在推理线上喂养错误解释，为真揭示蓄能。机制要点：虚惊必须走完完整的预期弧，否则观众来不及上钩。
- 基准时长区间：2.5–5.0 秒
- 强度缩放规则：1→2.5s / 3→3.5s / 5→5.0s（强度越高越长：误导越重要，假弧越要做真）。
- 不适用反例：镜内没有解除、把误导留到后文才揭穿的镜（前半用 suspense_reveal，揭穿时用 twist_reveal）；纯气氛惊吓练习、不服务任何后续揭示（删，或降级为 transition）。

### twist_reveal 反转揭示

- id：`twist_reveal`
- 中文名：反转揭示
- 定义：一条信息落地，使已发生的一切被重新定性的镜头。
- 叙事功能：执行「认知重加工」——观众需要在镜内完成「啊，原来之前是那样」的倒带；它不靠蓄压而靠落差，落地后要停留到重加工完成。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：颠覆越彻底，倒带越久）。
- 不适用反例：逐步显形、观众早有预期的揭示（用 suspense_reveal）；反转之后人物的认知反应（用认知反应）。

### comic_beat 喜剧节拍

- id：`comic_beat`
- 中文名：喜剧节拍
- 定义：喜剧因果链中的一个主要阶段：建立预期、延迟兑现或形成反差结果。
- 叙事功能：管理预期与结果之间的时机和落差；阶段可以跨越多个镜头，也可以在一个连续镜头中完成，不规定切法或镜头数量。
- 基准时长区间：1.5–4.0 秒
- 强度缩放规则：1→4.0s / 3→2.5s / 5→1.5s（强度越高越短：越大的笑点切口越脆）。
- 不适用反例：靠台词本身逗乐、画面只是承载对白的镜（用 dialogue）；笑点之后观众的笑声缓冲/人物无奈（用 reaction_listen 或 emotional_aftermath 短档）。

### standoff 对峙僵持

- id：`standoff`
- 中文名：对峙僵持
- 定义：冲突双方暂未采取决定性行动，局势处于相持或等待变化的状态。
- 叙事功能：让观众感受到尚未解决的力量关系与选择压力；紧张感可以来自行动、信息、空间、时间或人物状态，不要求画面静止。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：僵局越死，相持时间越长，观众对局势变化的等待越强）。
- 不适用反例：对峙中已经开始言语交锋（用 negotiation）；僵局被打破后的第一动（用 action_exchange 或 scare_climax）。

### negotiation 谈判攻防

- id：`negotiation`
- 中文名：谈判攻防
- 定义：以言语为武器的回合制交锋镜头——报价、施压、让步、反将。
- 叙事功能：每个镜头是一个「回合」，改变双方的筹码分布或信息归属；看点在权力天平指针的来回，而非信息传递本身。与 dialogue 的区别：dialogue 交换信息，negotiation 交换地位。
- 基准时长区间：2.0–4.0 秒
- 强度缩放规则：1→4.0s / 3→3.0s / 5→2.0s（强度越高越短：局势变化越密集，观众越需要快速接收新的筹码或态度变化；不规定切换频率或画面组织方式）。
- 不适用反例：一方单向倾诉无回合结构（用 confession 或 dialogue）；交锋升级为肢体冲突（用 action_exchange）。

### time_compression 过程压缩

- id：`time_compression`
- 中文名：过程压缩
- 定义：让观众在有限叙事时间内理解一段较长过程已经推进或完成。
- 叙事功能：突出过程的结果、变化或时间跨度；可通过连续呈现、概括、跳跃或其他适合本段的方式表达，不要求蒙太奇或切碎动作。
- 基准时长区间：1.0–2.5 秒
- 强度缩放规则：1→2.5s / 3→1.5s / 5→1.0s（强度越高越短：压缩比越大，单元越碎）。
- 不适用反例：单个完整动作单元（拆断完整动作凑蒙太奇是禁项）；过程中发生了必须让观众看清的关键事件（该事件独立成镜，按其实际功能贴类）。

### silent_beat 静默拍

- id：`silent_beat`
- 中文名：静默拍
- 定义：言语或主要行动暂缓，观众有机会感受先前事件的影响或当前关系状态。
- 叙事功能：让情绪、信息或关系变化获得消化时间；静默可以与动作、环境变化或摄影运动并存，不要求画面空置或完全静止。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：越重的静默越要敢于停）。
- 不适用反例：静默中有未闭合威胁预期在爬升（用 dread_build）；只是没写清楚功能的过渡空镜（先回答叙事功能，再决定贴不贴）。

### ritual 仪式拍

- id：`ritual`
- 中文名：仪式拍
- 定义：一项行动因其规则、重复或象征意义而具有仪式性。
- 叙事功能：让观众理解行动的形式意义、参与者关系或仪式受到改变时的后果；不规定重复次数、对称构图或视觉符号。
- 基准时长区间：2.5–6.0 秒
- 强度缩放规则：1→2.5s / 3→4.0s / 5→6.0s（强度越高越长：程式越完整，越要不吝时间把每个步骤做足）。
- 不适用反例：有实用目的、不看形式看结果的操作过程（用 time_compression）；仪式被意外打断的那一刻（按打断性质贴 scare_climax 或 twist_reveal）。

### plant_setup 伏笔铺设

- id：`plant_setup`
- 中文名：伏笔铺设
- 定义：让一个日后回收的细节（道具、台词、习惯、画面元素）被观众「看见但没多想」的镜头。
- 叙事功能：在观众记忆中建立一个稍后可能产生意义的细节、关系或事实；是否突出以及突出程度由故事需要决定，避免过早暴露其后续用途。
- 基准时长区间：1.5–3.0 秒
- 强度缩放规则：1→1.5s / 3→2.0s / 5→3.0s（强度越高越长：伏笔越关键，越要确保登记成功，但 3.0s 封顶防止预告化）。
- 不适用反例：铺设对象本身就是当前场面焦点（用 exposition 或 suspense_reveal）；伏笔回收镜（用 payoff 或 twist_reveal）。

### payoff 伏笔兑现/高光兑现

- id：`payoff`
- 中文名：伏笔兑现/高光兑现
- 定义：回收早前伏笔或兑现全片承诺的高光镜头——观众认出「原来是它」并完成意义闭环。
- 叙事功能：把存款连本带息取出：观众需要认出旧元素、接通新语境、体验兑现快感，三段认知缺一不可，因此它有全局地板约束（见 §5 `role_floors.payoff_s`），与「高光兑现镜 ≥5s」的节奏极值锚定规则同源。
- 基准时长区间：5.0–8.0 秒
- 强度缩放规则：1→5.0s / 3→6.5s / 5→8.0s（强度越高越长：兑现越重，闭环仪式越要完整；超过 5.0s 必须写明镜内信息注入）。
- 不适用反例：兑现瞬间之后的庆祝/代价展示（用 emotional_aftermath 或 defeat_beat）；无伏笔存根的新信息揭示（用 twist_reveal——无账可取不叫兑现）。

### defeat_beat 挫败拍

- id：`defeat_beat`
- 中文名：挫败拍
- 定义：人物遭遇重大失败、计划破产或信念崩塌，并开始承受其后果。
- 叙事功能：让观众理解失败对人物、关系或后续选择造成的损失；痛感可以通过行动、反应、环境或信息变化表达，不要求人物静止。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：挫败越彻底，触底越要坐实）。
- 不适用反例：失败正在发生的动作镜（按动作类贴）；挫败之后的颓废蒙太奇（用 time_compression 或 emotional_aftermath）。

### chase_escalation 追逐升级

- id：`chase_escalation`
- 中文名：追逐升级
- 定义：追逐或行动中的风险、代价或失败可能性持续上升。
- 叙事功能：让观众感受到局势升级和可用余地减少；通过行动结果、空间、时间、信息或节奏变化实现，不规定剪辑速度或镜头时长递减。
- 基准时长区间：1.0–2.5 秒
- 强度缩放规则：1→2.5s / 3→1.5s / 5→1.0s（强度越高越短）。
- 不适用反例：追逐的常速巡航段（用 action_chase）；升级后撞上高潮的那一下（用 scare_climax）。

### tension_beat 关系张力

- id：`tension_beat`
- 中文名：关系张力
- 定义：关系中存在尚未表达、确认或解决的情愫、欲望、敌意或依赖。
- 叙事功能：维持关系走向的未决状态；张力由当前关系事实和选择构成，不预设人物动作、距离或视线设计。
- 基准时长区间：3.0–6.0 秒
- 强度缩放规则：1→3.0s / 3→4.5s / 5→6.0s（强度越高越长：张力越满，悬置越要撑到观众替人物着急）。
- 不适用反例：张力已经说破进入对白交锋（用 dialogue 或 negotiation）；张力闭合的拥抱/亲吻落点镜（用 emotional_aftermath 或 payoff）。

### exposition_managed 受控信息倾倒

- id：`exposition_managed`
- 中文名：受控信息倾倒
- 定义：故事必须交代较复杂的信息链、前史或规则体系，且观众需要理解其因果关系。
- 叙事功能：把复杂信息分解为观众能够处理的因果单元；单元可在镜头、对白、行动或场景之间组织，不要求每镜只递送一块信息。
- 基准时长区间：2.5–4.5 秒
- 强度缩放规则：1→2.5s / 3→3.5s / 5→4.5s（强度越高越长：信息关系越复杂，观众理解其因果所需时间越多；时长变化不要求拆分镜头或切碎内容）。
- 不适用反例：单条轻信息（用 exposition）；信息倾倒实为人物倾倒情绪（用 confession）。

### action_exchange 攻防回合

- id：`action_exchange`
- 中文名：攻防回合
- 定义：攻防双方的一个交锋阶段，其结果改变行动优势、位置、伤势或风险。
- 叙事功能：帮助观众理解行动因果及其代价；一个镜头可覆盖一个或多个连续动作阶段，是否拆分由清晰度、连续性和戏剧效果决定。
- 基准时长区间：1.0–2.5 秒
- 强度缩放规则：1→2.5s / 3→1.8s / 5→1.0s（强度越高越短：回合越到胜负手越连环加速）。
- 不适用反例：无对手的位移动作（用 action_chase）；回合结构崩坏、刻意模拟主观混乱的段落（用 panic_fragment）。

### contemplation 持续观察

- id：`contemplation`
- 中文名：持续观察
- 定义：让观众持续观察一个日常行为、空间状态或人物处境，使经过的时间本身具有表达作用。
- 叙事功能：让观众从等待事件转向感受存在、关系或环境的质地；时间感来自场面内容与观众注意力的共同作用，不限定固定机位、留白或镜头长度。
- 基准时长区间：5.0–8.0 秒
- 强度缩放规则：1→5.0s / 3→6.5s / 5→8.0s（强度越高越长：凝视越彻底越接近凝视本身的目的；需要超过 8.0s 时走一镜到底/长镜豁免路径，不改区间）。
- 不适用反例：凝视中有威胁预期在积累（用 dread_build——观察与监视是两回事）；只是还没想好怎么切的长镜（先回答功能）。

### panic_fragment 认知失序

- id：`panic_fragment`
- 中文名：认知失序
- 定义：人物的感知、记忆或判断暂时失去稳定，观众也难以完整掌握局势。
- 叙事功能：让观众体验信息缺失或认知失序；呈现程度应服务当前戏剧目的，并保留理解后续行动所需的信息，不预设镜头长短或视听手段。
- 基准时长区间：0.8–2.0 秒
- 强度缩放规则：1→2.0s / 3→1.4s / 5→0.8s（强度越高越短）。
- 不适用反例：观众需要看清因果的关键动作（用 action_exchange——慌乱不能吃掉叙事责任）；事后回放的同一段动作（按回放功能重新贴类）。

### confession 独白倾诉

- id：`confession`
- 中文名：独白倾诉
- 定义：人物卸下防御的长段独白，或旁白式自我陈述的承载镜头。
- 叙事功能：通过自我陈述呈现人物的立场、隐瞒、理解或防御变化；画面如何承载言语和潜台词由导演结合信息、表演与场景关系决定。
- 基准时长区间：4.0–8.0 秒
- 强度缩放规则：1→4.0s / 3→6.0s / 5→8.0s（强度越高越长：防御剥落得越深，越要不打岔地陪到底；有台词时按对白时长预算公式，锚点为无台词参照）。
- 不适用反例：有来有回的言语交锋（用 negotiation 或 dialogue）；独白内容实为信息倾倒（用 exposition_managed）。

## §3 风格节奏档案

风格档案描述整体节奏感受，不规定 beat_type 的选择顺序、出现比例、镜头数量或摄影/剪辑方法。导演先依据当前故事独立决定节奏走势；只有需要时，机器表中的区间校准才影响已选节拍的时长。表中列出某个「风格 × 节拍」组合，只代表该组合的时长校准，不表示该风格必须或优先使用该节拍。

### horror_dread 恐怖/怪谈

- 节奏气质：允许预期、兑现与余波之间形成强弱反差；具体起伏由威胁机制和观众掌握的信息决定。

### comedy 喜剧

- 节奏气质：强调预期建立、时机偏差与结果反差；停顿长短和呈现方式由笑点机制决定。

### wuxia_action 武侠动作

- 节奏气质：行动因果与力量变化清楚，节奏可在蓄势、交锋、失衡和结果之间变化；不规定招式对应镜头或动作节拍。

### noir 黑色电影

- 节奏气质：强调信息不对称、人物策略与潜台词之间的压力；速度和停留由当前信息关系决定。

### slow_cinema 生活流长镜

- 节奏气质：允许日常行为、关系和时间感成为叙事内容；事件稀疏或停留较久都必须来自当前场景的观看价值，不要求长镜或静止画面。

### anime_stylized 动画番剧演出

- 节奏气质：允许形式化节拍、重复、突变和风格化表达；其使用由作品视觉规则与当前戏剧目的共同决定。

### platform_feed 平台信息流短剧

- 节奏气质：重视开场观看承诺、信息可读性和持续的因果推进；不以固定秒数、镜头数或快切作为普遍要求。

### mystery_detective 悬疑推理

- 节奏气质：管理线索、观众推断与揭示之间的先后关系；信息给出的速度应让推断既可能又不被过早封死。

### romance_art 爱情文艺

- 节奏气质：关系变化、接近与回避、表达与未表达都可构成张力；不规定停留、沉默或特定视线模式。

### documentary 纪录片式

- 节奏气质：尊重事件自身的连续性和偶发变化；是否干预及如何组织材料取决于事实关系、叙事伦理和观看清晰度。

## §6 参数调参说明（维护者阅读）

> 本节面向修改节奏参数的维护者，解释各参数的导演语义与调参影响；日常分镜制作不需要读——只需在引用参数名时知道「数值以 §5 表为准」。

**speech.\*（语音时长预算）**：对白镜时长的推导公式为「台词字数 ÷ chars_per_s + onset_s + reaction_s + 余量」。`chars_per_s_normal: 4` 与 `chars_per_s_rapid: 5` 是常态/急速两档中文配音语速；`onset_s: 0.5` 是台词起音前的入场留白，`reaction_s: 0.5` 是台词落点后的反应留白，`min_overhead_s: 0.3` 是任何含语音镜的最小附加余量。调参影响：语速值上调会系统性压缩全部对白镜时长、推高全片剪辑速率；onset/reaction 是对白镜的情绪地板，压到 0 会让对白失去呼吸感，台词完整性与节奏档位冲突时以台词为准。

**rounding_grid_s（取整网格）**：所有推导出的期望时长向 0.5 秒网格收拢。调大网格会让节奏更「粗」但切点漂移容忍度更高；调小则计划更精细但生成端漂移更容易出格。

**role_floors.\*（角色地板）**：高光兑现镜（payoff）与本集最终镜（final）的时长地板均为 5.0 秒，对应节奏极值锚定中「最长拍必须真实存在」的规则。确需短促切断（留扣式收尾）时不改地板值，走例外登记。

**shot_bounds.\*（单镜计划范围）**：单镜计划范围通常为 0.8–8.0 秒；具体一镜到底及长镜豁免按 `storyboard.md` 判断。`info_injection_threshold_s: 5.0` 是复核提示：超过该时长且未标记 `info_injection` 时，引擎提醒创作者确认镜内发展或停留意图；提醒不代表设计失败，也不自动要求切开。镜长由节拍、对白、动作、观看和生成能力共同决定。

**kf.\*（关键帧预算）**：每集关键帧 `min: 3`、常规上限 `base_max: 4`；单集超过 `long_episode_threshold_s: 300` 秒后，每超出 `step_s: 180` 秒上限加 1，`cap: 6` 封顶；每个 SEG 最多 `per_seg_max: 2` 张。调参影响：cap 决定一集视觉锚点的记忆预算，per_seg_max 防止单个段落吃光全集关键帧。示例：510 秒长集触发长集档位、关键帧上限由 4 升至 5（数值仅演示格式）。

**high_density.\*（高密度段形态）**：`min_shots: 8` 仅作高密度短段的诊断参考，不是质量门或增镜配额；镜数由可见信息事件、动作职责、表演反应与自然切点决定，不按是否恰为 15 秒触发。`golden_window_s` 与 `first_shot_max_s` 只在项目规划明确采用信息流黄金三秒目标时作为参考，不由 H3 技术上限自动触发。不得为满足这些参考值拆断动作或改写镜长。示例：14 秒高密度段排 9 镜、段 ASL 约 1.6s 属正常形态（数值仅演示格式）。

**asl_targets.\*（段级 ASL 目标）**：dialogue_emotional 与 suspense_build 段的目标平均镜长 2.5–4.0 秒，micro_film 段 3.0–6.0 秒。这是段级健康度判定标尺，与单镜 beat 区间是两层指标：单镜可以出格（走例外），段均值应落带内。

**health.\*（节奏健康度阈值族）**：分布健康的判定常量——`segment_min_range_s: 1.0` 段内时长极差下限；`flatline_window_s: 2.0` 与 `flatline_max_share: 0.7` 判定分布扁平（任一 2 秒窗内镜头占比超 70% 必须按强度重分配）；`fast_pole_max_s: 3.0` 要求含 §4 `fast_pole_capable=yes` 的快节奏节拍（惊吓/动作/切口类）时最短镜 ≤3 秒（快极存在）——是否触发只看 §4 显式标记，不由锚点数值推断；`slow_pole_min_s: 6.0` 与 `slow_pole_min_total_s: 300` 要求长片最慢镜 ≥6 秒（慢极存在）；`beat_monoculture_max_share: 0.6` 单一 beat_type 占比上限；`cap_uniformity_min_segments: 8` 与 `cap_uniformity_share: 0.85` 判定段落镜数均匀化（防节拍器结构）；`speech_voice_max_share_normal: 0.55` / `speech_voice_max_share_dense: 0.7` 为常态/高密度段的语音时长占比上限（防台词灌满挤压画面叙事）。

**shot_count_risk_threshold（镜数风险阈值）**：单段镜数达到 6 即触发生成端合并相邻镜/丢弱镜的风险标注，需在批次确认中点名；它不是镜数上限，是风险提示线。
