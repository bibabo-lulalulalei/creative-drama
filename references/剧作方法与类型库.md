# 剧作方法与类型库 Reference

> 本文件提供故事开发、人物关系、场景、系列、改稿与类型方法。按当前创作问题定位相关小节，将判断落实到作品；不整库预读，不另写逐项推导报告。正式生产的产物、状态与字段由 `scriptwriter.md` 和 `manifests.md` 规定，纯文字创作按委托范围使用方法。

## 第一部分：编剧室方法

### 使用合同

- 先验证故事为什么成立，再写对白和镜头感。视觉风格不能替代人物选择与因果。
- 方法按作品性质和规模取用；行动故事须有可信的目标与后果，观察、等待、恒定人物或开放结构不必硬补一套攻防阶段。
- 类型承诺读取本文件第二部分，可调用元素读取 `题材亮点与传播库.md`；类型承诺必须转译成人物选择、冲突、后果和可见证据，不能写成抽象标签。模板只能提供起点，必须改造成当前人物不可替换的行动。
- 不用固定幕数、固定反转数或固定秒点证明剧本质量。
- 来自检索、GitHub skill、编剧文章或用户参考图的结构方法只能作为诊断和改写工具，不得覆盖用户要求、已确认规划或正式剧本格式，禁止把它们当成必须逐项套用的剧情模板。

### 结构模型工具箱

选择最能解决当前问题的一种或两种结构模型即可，不整包叠加。结构名不写进正式剧情，必须转译为当前人物的具体事件、选择和后果。

| 模型 | 适用场景 | 吸收方式 | 失败信号 |
|---|---|---|---|
| 故事脊柱 | idea 松散、因果像流水账 | 日常模式 -> 打破模式 -> 因为如此连续后果 -> 最终选择 -> 新常态 | 只有“然后”，没有“因此” |
| 弗赖塔格金字塔 | 单集或微电影需要情绪坡度 | 铺垫、激励事件、冲突上升、高潮、回落和结局都落成场面变化 | 高潮很吵，但前面没有逐级加压 |
| 英雄之旅 | 冒险、成长、奇幻、任务型故事 | 普通世界、召唤、越界、试炼、核心危机、奖赏和返回按时长压缩为可见阶段 | 只有换地图，没有人物内在变化 |
| B 故事/副线 | 主线单薄、人物关系平 | 副线必须测试主角、反照主题、揭示性格或改变主线筹码 | 副线可整段删除且主线不变 |
| 豪格六阶段 | 外部目标有了但人物弧弱 | 同时规划外部旅程和内部旅程，让每个转折都逼近或撕裂人物真实需要 | 事件推进了，人物还是同一个人 |
| 15 beat / beat sheet | 长片、长剧或结构诊断 | 以当前故事节点检查因果和观看进程，不按百分比分配时间或凑齐节拍 | 写出“中点反转发生”，但没有发生什么 |

### 一、故事前提压力测试

需要校准前提时，用一段话说明当前作品最关键的人物处境与牵引：

```text
一个处于何种缺口中的主角，为了什么可观察目标，在什么时限或压力下，
必须对抗怎样的对立力量；如果失败会失去什么；这个过程为什么迫使其
面对自己最不愿承认的问题；最终必须做出什么不可逆选择。
```

下表用于诊断行动型前提，不是所有故事必须填满的六格；反讽、时限与不可逆选择按作品需要采用：

| 检查 | 达标问题 | 失败信号 |
|---|---|---|
| 主体 | 谁必须行动 | 换任何人都能完成故事 |
| 欲望 | 主角具体争取什么 | 只想“变好”“成功”“被爱” |
| 对立 | 谁也有合理目标和资源 | 对手只等着被打败 |
| 代价 | 失败和成功分别会失去什么 | 赢了没有代价，输了也无所谓 |
| 反讽 | 人物最不擅长的事为何偏偏是解法 | 设定和人物互不影响 |
| 选择 | 高潮为何只能由此前选择造成 | 靠巧合、新设定或外援收尾 |

若卖点只剩标签，先把既定方向具体到人物经验和可观察场面；只在确实推翻已确认方向时返回规划，不因初稿不够具体就重选故事。

### 二、主题命题

主题不是口号，而是一组会让人物付出代价的对立价值，例如“真相是否永远比关系重要”“保护能否成为控制”。

为主题建立：

- `value_a`：主角开场相信的价值及其现实收益。
- `value_b`：故事不断逼近、但主角抗拒的另一种价值。
- `counterexample`：证明 A 并非全错、B 也非万能的人物或事件。
- `climax_choice`：高潮中必须牺牲一部分价值才能完成的选择。
- `ending_evidence`：结局用行为和后果回答，不由角色总结主题。

### 三、人物引擎

按当前人物需要选择下列问题，写清真正驱动行为的因素；不为填满表格给每个人硬造秘密、创伤、错误信念或越界：

| 字段 | 含义 |
|---|---|
| 外在欲望 | 本剧中可观察、可失败的目标 |
| 内在需要 | 人物必须学会、承认或放下的东西 |
| 错误信念 | 曾保护人物、如今正在伤害人物的判断 |
| 创伤或形成事件 | 错误信念为何可信，不用于廉价卖惨 |
| 优势与阴影 | 同一性格如何既帮助又制造问题 |
| 秘密 | 一旦公开会改变谁的选择 |
| 底线 | 人物自称绝不做什么 |
| 越界选择 | 哪个节点迫使其跨过或重写底线 |
| 代价 | 每次升级失去的关系、资源、身份或自我认同 |
| 行为签名 | 说话、回避、施压、求助和撒谎的独特方式 |

成长弧可表现为旧策略失效后的新选择，不只“从弱变强”；恒定弧、失败弧和未完成的变化也成立。先确定作品需要哪一种，不要求人人蜕变。

### 四、人物关系张力矩阵

项目级关系定义写入 `剧本_全局设定与分集总纲.md` 的“全局故事圣经”章节；每集在 `script_contract_ep_N.json` 的 `relationship_tension` 登记变化。每对核心关系至少记录：

| 关系 | 双方表面目标 | 双方隐藏需求 | 权力差 | 信息差 | 情感差 | 依赖与筹码 | 开场距离 | 变化节点 | 结尾距离 | 下集压力 |
|---|---|---|---:|---:|---:|---|---|---|---|---|
| CHR001↔CHR002 |  |  | -2~+2 | -2~+2 | -2~+2 |  |  | 场次+事件+选择 |  |  |

数值只用于比较变化方向，不是客观心理测量，也不要求给所有角色配对评分。正式合同需要关系值时，`-2` 表示前者明显受制或落后，`0` 表示暂时均衡，`+2` 表示前者明显占优或更知情/投入。真实变化绑定具体处境与事件，关系未改变也可如实记录。

关系矩阵向导演阶段提供调度意图，但不直接规定“强者站高处”之类固定符号。导演需结合空间、人物伪装和场景反讽决定站位、距离、遮挡与视线。

### 五、信息差与揭示账本

悬疑、误会、身份、秘密、规则和计划统一登记：

| 信息 ID | 故事事实 | 观众知道 | 主角知道 | 对手知道 | 公平线索 | 错误解释 | 揭示位置 | 揭示动作 | 后果与回收 |
|---|---|---|---|---|---|---|---|---|---|

- 反转必须重释既有事实，不是临时添加新事实。
- 公平线索第一次出现时应自然承担当前场景职责，不能只为将来解谜而显眼摆放。
- 揭示须使此前事实或后续选择具有新意义；反应可以延迟、被隐瞒、留在画外或与行动并行，不要求独立反应镜头或当场转策略。
- 观众领先角色产生焦虑或优越感；观众落后角色产生谜团；两者按类型承诺选择。

### 六、场景发动机

行动场景写不清时，可用下列问题诊断；已有正文或合同表达清楚就不另填内部卡。观察、仪式与等待场按自身观看价值判断：

```text
入场价值：场景开始时，权力/关系/认知/危险/希望处于什么状态
即时目标：主行动者现在要让谁做什么
策略：先用什么具体办法
反制：对方如何识破、拒绝、转移或加价
升级：主行动者换什么更冒险的策略
转折：哪条新信息、行动或代价改变场景方向
离场价值：状态怎样改变、累积或保持未决
余波：本场如何影响后续观看或行动
```

对白写不活时，辨认试探、拖延、安抚、交换、撒谎等实际语言动作即可，不逐句加标签。复沓、犹豫、失语和拒绝回应也可能重要；结合整场判断删并损失，不因相邻一句没有新信息就删。

#### 常见场景策略

先判断这场戏承担什么功能，再选择策略。一个场景可以兼具两种功能，但必须有一个主功能；否则容易写成“什么都想要，结果只是在解释背景”。

| 场景功能 | 何时使用 | 可用策略 | 关注作用 | 常见失败 |
|---|---|---|---|---|
| 开场钩子场 | 首集、单片开头、阶段转折开头 | 从结果先行、异常画面、冲突开门、身份错位、倒计时、秘密暴露或反常行为中选一种；第一画面必须让观众产生具体问题 | 观众知道主问题或关系异常，主角被迫行动 | 旁白介绍身世、早晨起床、走路进场、只炫风格 |
| 目标建立/任务派发场 | 需要让观众明白主角为何行动 | 把目标写成可观察、可失败、可计时的事；同时给出资源限制和失败代价 | 主角从“想”变成“必须做” | 长辈/上司讲设定，目标抽象成成功、成长、被爱 |
| 对峙/羞辱/压迫场 | 需要制造愤怒、压力或权力差 | 对手使用具体资源压主角，如钱、职位、名声、证据、关系、规则或公开场合；主角不是纯挨打，至少有观察、忍耐、反问、取证或隐藏底牌 | 权力差、名誉、资源、证据或关系位置变化 | 连续几场只是换人羞辱，主角没有策略 |
| 谈判/交易/逼供场 | 双方都有筹码且不能直接动手 | 每轮台词都要有要价、交换、试探、威胁、让步或揭底；把筹码落到物件、文件、时间、见证人或不可撤销承诺上 | 至少一方让出筹码、暴露底牌或改变条件 | 两人原地吵架、互相解释动机，没有新信息 |
| 调查/找证据场 | 悬疑、背叛、职场、家庭秘密等 | 问题驱动行动：提出假设，寻找物证，得到线索，先产生错误解释，再推向更大的问题 | 观众、主角或对手的信息差变化 | 主角只是看监控/翻手机就得到答案，调查没有代价 |
| 反击/爽点兑现场 | 主角从受压转为主动 | 前面压力必须足够具体；反击方式要出乎意料但有铺垫，命中对手最在乎的资源、身份、关系或规则 | 主角获得阶段回报，同时产生更高价格或新敌意 | 突然亮身份、突然有钱、突然开挂，对手只震惊 |
| 情感靠近/疏离场 | 爱情、亲情、友情、自我关系 | 表达服从人物需要，可直说、回避、共同做事或拒绝回应；旧物和微动作并非必选 | 亲密、信任、亏欠、边界或防御方式怎样被体验 | 只用作者总结替代人物具体交流 |
| 秘密揭示/反转场 | 身份、动机、事实、规则被重释 | 回收公平线索，使新理解产生作用；反应与后果可延迟或画外 | 旧解释怎样失效，下一步选择怎样受到影响 | 突然新增真相，或只报答案而没有意义变化 |
| 失败/低谷场 | 中段压迫、高潮前最低点 | 让主角旧策略彻底失效，并失去一个真实资源：人、钱、证据、名誉、时间、身体状态或自我认同 | 主角不能回到旧办法，必须改策略或越界 | 只是更惨、哭得更多，没有新选择 |
| 行动/救援/追逐场 | 任务、危机、灾难、动作类型 | 明确空间目标、障碍和资源；保留理解决策、接触与结果所需的连续过程，不把动作阶段等同于镜头 | 任务条件、人物位置、资源或伤亡风险变化 | 动作很热闹但看不清目标，胜负不改变剧情 |
| 喜剧/误会场 | 搞笑、轻喜、荒诞、反差人物 | 双方都依据合理但不完整的信息行动；误会每轮扩大后果，最后回扣到人物弱点、规则漏洞或关系变化 | 笑点造成真实麻烦、真相或关系后果 | 只有段子和热梗，笑完人物还是原样 |
| 公共场面/群体围观场 | 婚礼、会议、课堂、直播、审判、宴会等 | 利用见证人、规则、座次、麦克风、屏幕、文件、投票或群体反应放大压力；公开信息必须改变私下权力 | 名誉、群体位置、联盟或规则归属变化 | 群众只负责惊呼，公开场合没有制度后果 |
| 日常/留白/微电影呼吸场 | 微电影、治愈、生活流、关系余味 | 从人物正在经历的生活和未决关系中寻找观看内容，允许沉默、无回应和时间经过，不强塞微动作 | 人物经验、空间、时间感或关系状态如何被感知 | 只为填时长加活动，删掉后观看经验毫无损失 |
| 集尾/片尾场 | 连续剧段尾或独立短片落点 | 按实际作品收束当前体验或承诺；可呈现结果，也可停在拒答、无回应或未决处。连续剧的后续动力有既有因果即可，不强补反应、新状态或危机 | 落点符合已经建立的观看关系和类型承诺 | 为追更随意截断事件，或为闭环强加解释、反应和余波 |

场景策略不能机械平均分配。短剧优先开场钩子、对峙、调查、反击、反转和集尾压力；微电影优先目标建立、情感靠近/疏离、失败低谷、日常留白和片尾余波；悬疑和职场多用调查、谈判和公开场面；家庭伦理多用日常事务、情感攻防和公共体面场。每次选择都要回到当前项目的主类型承诺和人物真实代价。

### 七、单集与系列发动机

#### 单集闭环

每集同时回答：

1. 本集向观众承诺解决什么具体问题。
2. 主角采用的第一策略为何失败。
3. 哪个选择让代价升级且无法完全回到开场。
4. 本集实际兑现了什么信息、情感或爽感。
5. 兑现后的后果如何自然建立下一问题。

集尾钩子不能无故吞掉本集已承诺的回报。开放结尾或延迟反应可以成立，但应来自已确认的叙事选择，不是为了追更随意截断事件。

#### 系列发动机

多集项目必须说明可重复但会升级的冲突单元：

```text
稳定欲望 + 可变案件/任务/关系难题 + 持续对立资源
+ 持续后果或重复中的变化 + 实际采用的跨集主线
```

若删除人物成长和跨集主线后，每集仍只是同一场“被辱后打脸”换皮，说明发动机不可持续。用升级阶梯规划对手资源、主角代价、关系裂痕、规则认知和行动尺度，不只升级反派音量。

### 八、传播句与记忆点

按作品需要判断是否有值得观众记住的语言、画面、声音或结构。传播句必须从人物策略、处境与后果中长出来；可以没有独立金句，不按每集数量或字数配额验收，不为传播改写用户原文。

### 九、分轮改稿

按当前作品的问题选择检查维度：前提与主题、结构与信息、人物、关系、场景、台词、导演与可拍性。发现哪类问题就定向修订并重读受影响内容；存在阻断问题时从最早失效点修订，重读并重做下游受影响内容，避免只补后文解释。不规定依次七轮、不强制每轮报告或固定审校次数。完成标准是具体问题得到解决、正式作品成立，格式与字数不能替代内容审校。

## 第二部分：类型剧作合同

> 本部分提供跨类型识别、类型承诺和剧作机制。需要确定主类型、子类型、混搭职责或诊断“像设定但不像该类型”时读取。呈现形态与创意变体继续读取 `题材亮点与传播库.md`。

### 一、类型坐标

不要用一个标签同时承担所有决策。每个项目分别确定：

| 维度 | 示例 | 决定什么 |
|---|---|---|
| 呈现形态 | 真人、动画、漫剧、数字人、口播、微电影 | 制作语法与可生成性 |
| 主类型 | 爱情、喜剧、悬疑、恐怖、动作、家庭 | 观众最核心的情绪承诺 |
| 子类型 | 甜宠、浪漫喜剧、本格推理、心理惊悚 | 场景与回报机制 |
| 世界背景 | 都市、校园、古代、未来、末世、架空 | 规则、资源和视觉空间 |
| 戏剧引擎 | 追查、逃生、竞赛、复仇、关系靠近、任务单元 | 故事如何持续推进 |
| 叙事结构 | 线性、倒叙、多视角、循环、单元+主线 | 信息释放顺序 |
| 情绪调性 | 明快、冷峻、荒诞、温柔、压抑 | 表演、节奏与结局余味 |
| 受众承诺 | 陪伴、宣泄、好奇、恐惧、浪漫、正义回报 | 什么必须兑现 |

混搭必须指定一个主类型。主类型决定高潮回报，辅助类型只提供压力、场景机制或调性。若爱情+悬疑最终只解释案件、没有完成关系选择，它仍是悬疑，不是爱情悬疑。

### 二、十四个类型家族

| 类型家族 | 核心承诺 | 主角发动机 | 对立机制 | 场景核心 | 高潮必须兑现 | 常见失败 |
|---|---|---|---|---|---|---|
| 爱情/甜宠/虐恋 | 看见两人为何靠近、为何不能靠近 | 渴望亲密又保护自我 | 身份、价值、时机、秘密 | 吸引与防御同时发生 | 对关系作出有代价的选择 | 只有误会、工业糖精、单方拯救 |
| 喜剧/黑色喜剧 | 预期被精确打破并不断升级 | 执着于错误目标或方法 | 社会规则与人物盲点 | 铺垫、误解、升级、回扣 | 最大错误造成最大真相或代价 | 只有梗，没有人物后果 |
| 家庭/伦理 | 亲密关系中的债、爱与边界 | 想维持家庭又争取自我 | 责任、代际、资源与旧伤 | 日常事务承载权力谈判 | 重新定义关系边界 | 单一恶人、靠哭诉和说教解决 |
| 职场/商战 | 能力、规则和利益的博弈 | 获得职位、项目、尊严或控制权 | 组织结构、竞争者、利益联盟 | 目标、筹码、交换、反制 | 用已铺垫能力完成不可逆决策 | 行业空心、靠身份开挂 |
| 校园/青春/成长 | 第一次选择如何塑造自我 | 获得归属、认可或独立 | 同伴规则、家庭期待、自我怀疑 | 群体位置与私密关系变化 | 主角为真实自我承担代价 | 成年人逻辑套学生、只有恋爱 |
| 悬疑/推理 | 公平线索最终形成可复盘答案 | 查明事实并修正判断 | 隐瞒者、误导、时间压力 | 线索、解释、验证、重释 | 真相由行动证明且改变局势 | 突降设定、对手降智、只靠口述 |
| 犯罪/惊悚 | 危险不断逼近，选择暴露人性 | 逃脱、追捕、掩盖或赎罪 | 制度、罪犯、时间、证据 | 风险升级和道德越界 | 生存结果与道德代价同时落地 | 只有阴暗气氛、暴力无因果 |
| 恐怖/怪谈 | 规则被触犯后的恐惧与未知 | 活下去、理解或阻止侵入 | 怪物、诅咒、群体禁忌、心理投射 | 建规则、犯规则、代价、局部验证 | 恐惧源或人物选择得到回报 | 全靠跳吓、规则临时变化 |
| 动作/冒险/灾难 | 清晰空间中的目标、障碍和代价 | 抵达、营救、夺取、守住 | 地形、敌人、时间和资源耗损 | 决策导致动作，动作产生结果 | 用能力与牺牲完成最终行动 | 动作与人物无关、空间不可读 |
| 科幻/高概念 | 一个规则如何改变人的选择 | 利用、逃离或修正规则 | 技术制度、悖论、资源限制 | 每次行动检验规则新后果 | 人物选择回答设定命题 | 设定解释过量、规则万能 |
| 奇幻/玄幻/仙侠 | 成长、奇观和价值体系的代价 | 获得力量、身份、归属或自由 | 等级、门派、命运、欲望 | 规则学习、能力应用、代价升级 | 终极能力选择体现人物价值 | 数值升级重复、金手指无代价 |
| 历史/古装/权谋 | 制度约束下的生存与选择 | 保全、上位、改革、复仇或守义 | 礼法、阶层、联盟和信息差 | 身份礼制就是行动条件 | 筹码、盟友与代价共同收束 | 现代口号换古装、计谋靠对手蠢 |
| 治愈/文艺/生活流 | 人物经验、时间感与关系带来的理解或余味 | 经历生活、等待、告别或重新连接 | 时间、沉默和现实限制 | 观察具体处境与相处方式 | 形成与作品相称的体验或落点，可保持未决 | 以空泛氛围或解释替代具体生活 |
| 儿童/合家欢/寓言 | 清晰愿望、想象与可理解后果 | 完成任务并学会合作或责任 | 具体规则、误解、自然障碍 | 重复中变化，危险可读 | 行动证明成长，不直接讲道理 | 成人化台词、恐惧过载、说教 |

社会议题、品牌剧情、音乐歌舞、体育竞技、医疗律政、公路、西部等作为“领域/子类型”接入最接近的主类型，再补充真实规则与专业事实。例如医疗悬疑仍以悬疑承诺为主，医疗提供证据条件；体育成长仍以成长或动作承诺为主，竞技提供目标和计分压力。战争军事、公益教育不得只当背景标签，必须按下一节选择专门题材路由。

### 三、十一种题材策略路由

用户给出的题材词不是完整策略。先选一条题材路由；合并词必须再选子路由，不能把“年代古风”“校园职场”“战争军事”“玄幻奇幻”“励志成长”“公益教育”当成同一种写法。题材路由决定冲突和回报，呈现形态决定如何把它拍出来，两者在 `题材亮点与传播库.md` 交叉。

| 题材路由 | 开写前必须决定 | 持续戏剧引擎 | 信息与场景策略 | 高潮/结局义务 | 主要禁区 |
|---|---|---|---|---|---|
| 情感 | 亲情、爱情、友情或自我关系；双方各自在乎什么 | 靠近、回避、维持或退出关系的需要与阻力 | 按人物口吻选择直说、倾诉、行动或潜台词，允许沉默和关系未决 | 关系体验与落点符合已建立的承诺，不强求和解或决裂 | 只靠误会拖延；单方拯救；硬煽情 |
| 家庭现实 | 家庭结构、资源归属、照护责任与旧伤 | 日常事务触发权力、责任和边界谈判 | 让钱、房、饭桌、照护、工作等现实事务成为场景动作 | 家庭规则或关系边界被重新定义，并展示余波 | 把一人写成纯恶；靠哭诉、说教或大团圆抹平现实 |
| 悬疑 | 本格推理、情感谜团、犯罪追查或生存惊悚；观众何时比主角多知道什么 | 问题→证据→假设→验证→重释，每轮改变嫌疑或危险 | 公平线索可见、误导有来源、关键答案由行动验证 | 当前核心问题得到可复盘答案，真相改变人物选择与局势 | 突降设定；侦探口述一切；只留坑不兑现 |
| 年代古风 | `年代` 走具体历史时期与生活制度；`古风` 走礼法、身份和权力秩序；可混搭但要分别立规则 | 人物欲望受到时代资源、身份制度与公共事件挤压 | 年代用劳动、物资、职业和生活细节；古风用礼制、称谓、文书、空间等级和联盟 | 人物在时代或制度约束下作出代价清晰的选择 | 现代价值口号换服装；年代物证失真；宫斗只靠对手降智 |
| 校园职场 | `校园` 选归属、第一次选择或成长；`职场` 选任务、利益、能力或组织权力 | 校园由同伴位置和自我定义推进；职场由目标、筹码、反馈和联盟推进 | 校园重群体场景与私密空间反差；职场重会议、交付、资源和决策后果 | 校园完成一次自我定义；职场用已铺垫能力完成不可逆职业选择 | 学生说成年人黑话；行业空心；把霸凌或压榨当成长捷径 |
| 战争军事 | `战争` 侧重战争中的人、家园与伦理；`军事` 侧重任务、指挥、协同与专业规则 | 明确任务→地形/敌情→资源和时间受限→计划受挫→重决策→代价 | 用地图、命令、侦察、通信、补给和空间因果传递信息；战斗必须改变任务条件 | 任务结果、人员代价和人物价值选择同时落地 | 只堆爆炸；战术空间不可读；神化牺牲；虚构冒充史实 |
| 玄幻奇幻 | `玄幻` 选等级、修炼、门派与因果；`奇幻` 选异世界规则、种族、魔法或神话系统 | 学规则→用能力解决问题→暴露限制→支付代价→价值选择 | 奇观必须承担叙事职责；能力、道具和禁忌先示范再升级 | 主角如何使用或放弃终极力量回答人物命题 | 战力数字替代剧情；规则随时改；金手指无代价 |
| 科幻 | 选一个能一句话说清的反事实规则，以及它不能做什么 | 人物试用规则→获得收益→发现二阶后果→规则反噬或伦理冲突 | 通过实验、失败和生活后果解释设定，少用百科对白 | 人物选择回答“技术改变条件后，人还坚持什么” | 设定万能；术语堆砌；最终靠新增规则解围 |
| 搞笑 | 人物喜剧、情境喜剧、讽刺、荒诞或黑色喜剧；笑点针对什么 | 明确预期→错误策略→误解升级→后果扩大→回扣 | 让角色认真追求目标，笑点来自行为与结果，不让角色替作者讲梗 | 最大笑点同时揭露人物真相、关系变化或现实代价 | 只有网络梗；配角只当捧哏；笑点不改变任何状态 |
| 励志成长 | `励志` 侧重困难中的持续行动；`成长` 侧重认知、能力与关系改变；明确外在目标和内在缺口 | 尝试→反馈→失败→学习/改变策略→更难选择，能力增长必须可见 | 用训练、工作、竞赛或生活任务呈现进步，并保留阶段性失败 | 成果由行动累积获得；即使未赢，主角也完成可证明的新选择 | 鸡汤替代过程；贵人包办胜利；用苦难数量冒充成长 |
| 公益教育 | `公益` 选要改变的公共认知或行为；`教育` 选要理解的知识、技能或选择后果；明确事实来源 | 具体人物遇到具体障碍→错误选择产生后果→获得帮助/新知识→实践改变 | 知识嵌入冲突、示范和选择；给受影响者主体性；关键事实须核验 | 观众既看见人物结果，也获得准确、可执行且不过度承诺的行动入口 | 口号式说教；苦难消费；污名化；用虚构数据或绝对化效果 |

#### 真实与敏感领域附加门

- 战争史、年代史、公益议题、健康、安全、法律和教育知识涉及真实事实时，先建立事实锁，记录来源、日期和不确定项；虚构改编必须明确边界。
- 真实案件与现实受害者不得为反转擅改关键事实、消费创伤或提供可模仿的伤害细节。
- 公益教育的“正确答案”也必须戏剧化：人物先面对选择和后果，再让知识改变行动；不能把角色变成宣传口。

### 四、混搭检查

每个混搭写清：

```text
主类型承诺：观众最后必须获得什么
辅助类型职责：只增加哪一种压力、乐趣或信息机制
共享人物问题：两种类型如何共同逼迫同一个人物选择
高潮归属：最终按哪一种类型完成回报
剥离测试：去掉辅助类型后，核心故事是否仍能识别；若不能，重新判断主次
```

### 五、类型校验

成稿后检查：

- 开场是否尽快提出该类型真正的问题，而不只是展示背景。
- 中段是否持续以该类型的独特机制升级，而不是通用争吵。
- 配角和场景是否提供不同策略，不只是重复主角信息。
- 高潮是否兑现主类型承诺，并让人物承担此前累积的代价。
- 结局余味是否符合已确认调性，同时完成事实与人物后果。
